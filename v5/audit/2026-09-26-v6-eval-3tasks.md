## Task B: GGUF 量化

**目标**：让 v6-final 可在 llama.cpp / ollama 上跑（减小体积）

### 流程

| 阶段 | 输出 | 大小 | 时间 |
|---|---|---|---|
| 源 | `Qwen3-14B-tdx-v6-final/` (HF safetensors) | 28 GB | — |
| HF → GGUF f16 | `Qwen3-14B-tdx-v6-final-f16.gguf` | 29.5 GB | 42 s |
| f16 → Q4_K_M | `Qwen3-14B-tdx-v6-final-Q4_K_M.gguf` | **8.58 GB** | 55 s |

**压缩比**：28 GB → 8.58 GB = 3.27x  
**平均精度损失**：4.87 BPW (4-bit quant, K-quant medium variant)

### 验证

通过 `llama-cpp-python` 加载 GGUF，alpaca prompt 输出符合训练格式（"建议持股观察/关注低吸/逢高减仓/观望"四档）。

### 工具

- **HF → GGUF**：`/tmp/llama.cpp/convert_hf_to_gguf.py` (latest llama.cpp)
- **量化**：`/snap/ollama/137/lib/ollama/llama-quantize`

### 产出
- `Qwen3-14B-tdx-v6-final-Q4_K_M.gguf` (8.58 GB)
- `Qwen3-14B-tdx-v6-final-f16.gguf` (29.5 GB, 中间产物)

## Task C: trigger 真值端到端

**目的**：用 v6-final-Q4_K_M 对真实 trigger 股票做端到端推理，验证模型能否识别"已触发"状态

**数据**：5 个 SH/SZ 真实 trigger 样本（range_pct ≥ 100%）

| symbol | market | start_date | end_date | range_pct | 实际触发 |
|---|---|---|---|---|---|
| sh110044 | SH | 2020-08-07 | 2020-08-11 | 121.99% | ✓ |
| sh110060 | SH | 2025-06-30 | 2025-07-23 | 107.21% | ✓ |
| sh110072 | SH | 2024-06-25 | 2024-07-03 | 141.10% | ✓ |
| sh113016 | SH | 2021-03-29 | 2021-04-20 | 150.09% | ✓ |
| sh113027 | SH | 2024-04-29 | 2024-05-29 | 107.44% | ✓ |

### 结果

| Case | Symbol | actual_trigger | model_recommends | 是否正确 | gen_time |
|---|---|---|---|---|---|
| 1 | sh110044 | True | False | ✗ | 31.9s |
| 2 | sh113027 | True | True | ✓ | 48.6s |
| 3 | sh110072 | True | True | ✓ | 30.4s |
| 4 | sh110060 | True | True | ✓ | 49.8s |
| 5 | sh113016 | True | False | ✗ | 46.2s |

**accuracy: 60% (3/5)**

### 解读

- **3/5 = 60%** 是合理起点 — 模型能识别"已大涨"应建议持仓，但还不能 100% 区分
- **2 错误样本** (sh110044 + sh113016)：model 推荐"观望/逢高减仓" — 实际触发过，可能因短期回调模型误判
- **推理速度**：40s/case (CPU 模式，GPU 被占) — 实际生产用 GPU 应 < 5s

### 产出
- `v5/audit/trigger_e2e_v6.json` — 5 case 完整结果
