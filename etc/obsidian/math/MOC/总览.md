> 本文件**不带** `#math-notes` 标签，避免把自己统计进下面各表。
> 所有查询均为**标签驱动**（`FROM #math-notes`），新增领域文件夹无需改动本文件。
> 需要装 **Dataview** 插件才会渲染；未装时只显示代码块，无害。

## 一、待证明 / 学习中（按最近修改排）

```dataview
TABLE domain AS 领域, level AS 层级, status AS 状态, file.mtime AS 最近修改
FROM #math-notes
WHERE !contains(file.folder, "06-模板")
  AND (status = "待证明" OR status = "学习中")
SORT file.mtime DESC
```

## 二、所有开放问题

```dataview
LIST
FROM #math-notes AND #开放问题

```

## 三、核心枢纽概念（入链最多）

```dataview
TABLE WITHOUT ID
  file.link AS 概念,
  length(file.inlinks) AS 被引次数,
  domain AS 领域
FROM #math-notes
WHERE !contains(file.folder, "06-模板")
SORT length(file.inlinks) DESC
```

> 注：`file.inlinks` 统计**所有**入链（含本总览与正文引用），不等于"被 `depends` 依赖数"。
> 精确的依赖反查放在每张卡内的 `## 与我已知网络的关系` 段（`contains(depends, this.file.link)`）。

## 四、各领域笔记计数

```dataview
TABLE length(rows) AS 笔记数

GROUP BY domain
```

## 五、体检查询（字段越界 / 缺失 / 到期）

```dataview
LIST
FROM #math-notes
WHERE !contains(file.folder, "06-模板")
  AND (!contains(["定义","定理","例子","反例","证明","开放问题","书索引"], type)
    OR !contains(["待整理","待证明","学习中","已掌握","开放问题"], status)
    OR !domain OR !level)
```

```dataview
TABLE next_review AS 下次复习
FROM #math-notes
WHERE !contains(file.folder, "06-模板") AND next_review <= date(today)
SORT next_review ASC
```

> 第二段**只有手工排期模式**才会命中：默认占位 `2099-12-31` 永不到期。
> 若改用 Spaced Repetition 插件调度（推荐），忽略本段，用插件的「Review Flashcards」队列。

## 六、孤儿笔记（无入链也无出链）

```dataview
LIST
FROM #math-notes
WHERE !contains(file.folder, "06-模板")
  AND length(file.inlinks) = 0 AND length(file.outlinks) = 0
```

## 七、质检：缺 `flashcards` 标签的笔记

> 带 `#math-notes` 且不在 `06-模板` 下的笔记，若 frontmatter `tags` 不含 `flashcards/<领域>`，
> Spaced Repetition 不会把它扫成卡组、进不了复习队列。下列笔记需要补标签（或主动删掉 flashcards 标签以退出复习）。
> `书索引` 是文献枢纽，默认不含 `flashcards`（见下方说明），已从下列列表排除。

```dataview
LIST file.link AS 笔记, domain AS 领域
FROM #math-notes
WHERE !contains(file.folder, "06-模板")
  AND !contains(["书索引"], type)
  AND !any(map(tags, (t) => startswith(t, "flashcards/")))
SORT file.folder, file.name
```

## 八、质检：缺 `tdx_link` 回指的笔记

> `tdx_link` 指向仓库内真实实现（如 `scripts/plan_e_backtest.py#deflated_sharpe_ratio`），打通「数学概念 ↔ 项目代码」。
> `书索引` 为文献枢纽，回指意义弱，已排除。下列概念卡建议补 `tdx_link`。

```dataview
LIST file.link AS 笔记, domain AS 领域
FROM #math-notes
WHERE !contains(file.folder, "06-模板")
  AND !contains(["书索引"], type)
  AND !tdx_link
SORT file.folder, file.name
```
