### 偏差解释（重要，不是矛盾）

实测日志同时给出两个数字：遍历结束时「正 215,653、负 1,079,225」；切分后「train 1,170,190 / test 124,688」。

**关键点**：负样本抽样只改变负样本保留量，**不改变哪些样本被判为正样本**。因此「正样本率偏高」这一缺陷，本质上**不受抽样比影响**——它反映的是**标签定义与过滤规则**的问题，而非采样比例问题。后续讨论「收敛至 1-2%」时，指的是**自然发生率**从 4.6% 降到 1-2%。

## 2. 次新股一字板不可交易样本：是否为噪声来源

### 2.1 结论：**机制上确认会引入噪声（方向性确认），但贡献量未经量化**

### 2.2 判断依据（三条，均基于工作空间实况）

| # | 依据 | 推理 |
|---|---|---|
| **①** | **标签定义必然吞入一字板** | 脚本第 6 行自述：`y = 1 当且仅当 close[t+1]/close[t] - 1 >= limit（T+1 收盘涨停，含一字板）`。标签只看**收盘价**，而一字板（开盘即封涨停、全天封死）**收盘价必然涨停** → **100% 被判为正样本**。 |
| **②** | **一字板实盘不可执行** | 打板要求在 T 日买入。一字板全天封死、卖单极少，**普通买单无法成交**（集合竞价与连续竞价均难买到）。因此这些"正样本"是**模型学得到、实盘买不到**的样本 → 纯粹的标签噪声。 |
| **③** | **次新股放大密度** | 新股上市初期存在连板效应（尤其无涨跌幅限制/特殊规则阶段），会形成**高密度、高纯度、不可交易**的正样本簇。脚本经核实**没有上市日龄（次新股）过滤**，`is_new` 未在该脚本中使用，仅以 `len(df) < 30` 过滤样本量不足的股票 → 次新股连板样本**全部进入训练集**。 |

**补充佐证（待验证）**：若把「一字板 / 次新股连板」从正样本中剔除，自然发生率从 4.6% 降到 1-2%，意味着当前约 **2/3 的正样本（约 7.4 万 / 11 万）为不可交易噪声**。此为**推算值，需分层统计验证**，不应直接当作结论。

### 2.3 样本过滤 / 设计逻辑的改进方向（WHAT）

以下按**优先级**排列，均为"需要做什么"层面的改进项，不含实现细节。

| 优先级 | 改进项 | 目标 |
|---|---|---|
| **P0** | **标签层区分「收盘涨停」与「可交易涨停」**：正样本须同时满足「次日收盘涨停」**且**「次日存在可成交买入窗口」（非一字、盘中有打开、或开盘非涨停但可排队成交） | 从源头消除不可执行正样本 |
| **P0** | **新增上市日龄过滤**：剔除上市不足 N 个交易日的样本（N 需按数据确定，建议先试 60 / 120 两档对比） | 直接消除次新股连板簇 |
| **P1** | **一字板显式识别与剔除**：在标签生成处按「开=高=低=收」或「开盘价已达涨停价」判定一字，命中的正样本予以剔除 | 精确定位不可交易样本 |
| **P1** | **量能/换手下限约束**：正样本要求次日成交量或换手率高于阈值，排除「无量封板」 | 保证正样本具备可成交性 |
| **P1** | **分层正样本率统计**：按上市日龄、板块、是否一字分层统计正样本率与 AUC，定位噪声集中区 | 用数据验证假设而非猜测 |
| **P2** | **验收口径迁移**：把模型验收阈值从「全量面板 AUC」改为「可交易样本 AUC」 | 避免污染基线误导切换决策 |

| **标题** | 打板样本集正样本率偏高（4.6%），疑由次新股一字板不可交易样本引入噪声 |

### 现象

- 过滤后自然正样本率约 **4.6%**，对应 **2400 只股票、约 11 万正样本**，显著高于预期的 **1-2%**。
- 观察到进程处于「I/O 遍历阶段」、RSS 约 2 MB，据此判断尚未进入训练；因权限问题无法终止。

### 影响

- **标签噪声**：一字板样本实盘无法买入，模型学到的模式不可执行。
- **验收失真**：AUC 在该样本上会被高估，若据此切换实盘模型存在实盘风险。
- **资源与迭代**：单进程约 3 GB / 66 线程，与同机服务争抢；基线不可作终值，后续对比需重跑。

### 根因推测

- **主因（机制确认）**：标签按 T+1 **收盘价**判定涨停，一字板必然涨停 → 不可交易样本 100% 被标为正。
- **放大因素**：次新股上市初期连板形成高密度正样本簇；脚本**未做上市日龄过滤**，亦**未显式识别并剔除一字板**。
- **认知偏差**：以「RSS 2 MB + 脚本自述阶段文案」推断进程状态不可靠（实测 2.95 GB / 66 线程）。

### 当前处理决定

- **不终止、不修改该进程**（已遵守）：进程已于 18:57:35 自行跑完，产物齐全，OOS AUC = 0.7612 基线已产出。
- **该基线仅作「含噪对照组」使用**，不作为切换实盘的验收终值。
- 本条缺陷先行记录，改造项纳入后续迭代。

### 后续迭代待办

1. **定义「可交易涨停」标签口径**，替代纯收盘价判定。
2. **补上市日龄过滤**，先试 60 / 120 日两档对比正样本率收敛情况。
3. **实现一字板识别与剔除**（或打标为不可交易单独评估）。
4. **加量能/换手下限**，排除无量封板。
5. **做分层统计**（上市日龄 / 板块 / 是否一字 × 正样本率 / 分组 AUC），量化噪声贡献。
6. **迁移验收阈值**至「可交易样本 AUC」，并与当前 `vpnl_huber_stage1` 在同口径下比较。
7. 上述项完成后**重建数据集并重训**，输出可比的新基线。
