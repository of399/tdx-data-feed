# daban min60 可执行性验证（2025-09-05 ~ 2026-09-24）

> 结论先行：**打板路径在 12.5 个月、5,221 只股票的 min60 数据上仍不可执行。**
> 触板即买的期望为负；封死后等开板再买更负；唯一为正的子集是
> 「事后知道收盘封死」或「一字板（买不到）」。连板≥3 接力基线仍为
> **+0.633%/笔（n=964，t=4.50）**，
> min60 封板质量没有提供可验证的增量 edge。
>
> 注（2026-10-22 更新）：这里的 +0.633% 使用了单笔收益异常价闸门，且 Part B 实际**未做任何跌停顺延**（直接在 T+1 收盘按收盘价卖出）。964 笔中 131 笔（13.6%）T+1 收盘跌停；补上 T+2 开盘顺延后为 **−0.036%/笔**，再把被闸门剔除的 75 笔（均值 −9.44%，49.3% 顺延）放回，同一时期纸盘全样本为 **−0.903%/笔**。详见 `DABAN_SALVAGE_20261022.md` 3.10 与 `DABAN_PAPER_TRADE_RULES_20261022.md` §13.4。本文的 +0.633% 应视为上界。

## 1. 数据与校验

- min60：4 根 60 分钟 K（10:30 / 11:30 / 14:00 / 15:00），5,221 只、256 个交易日、20250905 ~ 20260924。
- 原始股票-日 1,316,465 行；剔除价格对齐异常 1,279 行（0.097%）后 1,315,186 行。
- 对齐校验：|min60 收盘 − 日线收盘| 的 P99.9 = 0.000000 元（最大 0.02），非零 0.085%。
- 触板 29,054 次；收盘封死 19,886 次（占触板 68.4%）；开盘一字 2,670 次。
- 封板后等待 1/2/3 根 K 的可成交（开板）样本：5,737 / 3,828 / 2,194 笔。
- 成本双边 0.30%；Part B 未实现跌停顺延（T+1 收盘直接卖）；异常价闸门为单笔收益 ∈ [−3×涨跌幅−2%, +2×涨跌幅+1%]。

- 与 `daban_backtest.py --mode chase` 同期 cb≥3 逐笔核对：共同 964 笔，gross 最大误差 5.0e-07；回测有 23 笔不在 min60 表中（平均 +4.041%），故本文基线略偏保守。

## 3. Part B：封板质量对连板≥3 接力的增量

### 3.1 基线

T 日收盘封死、连板≥3，T+1 开盘买入（开盘涨停剔除）、T+1 收盘卖出。原始 1,538 个信号，T+1 开盘涨停买不进 499 个（32.4%），异常价 75 个，最终 **964 笔 / 250 天**。

- 均净 **+0.633%/笔**（账面，未做跌停顺延），胜率 52.6%，日均 +1.010%，日度 t **4.50**。
- 基线账面为正且显著；补上跌停顺延后为负（见顶部注）。问题是有没有 min60 特征能在池内继续区分好坏。（日均按交易日等权，逐笔均值按每笔等权，二者因每日笔数不同而不同。）

### 3.5 迟到量能候选：看起来最好，但不够稳

把 T 日 15:00 这根 K 的成交量占全天比例（`last_bar_vol_share`，T 日收盘即可知）按中位数 2.51% 分组：

- 高组 +1.055%/笔（n=482，相对 0 的 t=4.18），低组 +0.210%/笔（n=482，t=0.86）。
- H1：高 +1.189% vs 低 +0.244%。
- H2：高 +0.897% vs 低 +0.197%。
- 同日配对价差：159 天，均值 +1.279pp/日，t=2.67，正价差天数 60.4%。
- 但剔除价差最大的 5 天后，均值降到 +0.825pp（t=1.84）；剔除 10 天后 +0.454pp（t=1.05）。价差集中在少数只有 2 笔交易的日子。
- 分位收益不单调：Q1~Q5 分别约 +0.68 / −0.24 / +0.90 / +0.79 / +1.05%/笔，低组被 Q2 拖累，而不是「量能越高越好」。
- 与一字板交互符号翻转：一字板内高量能组 +0.38% vs 低量能组 +1.40%；非一字板内 +1.00% vs −0.05%。
- 高量能组 T+1 开盘涨停买不进率 36.9%，低量能组 27.2%，高组本身被剔掉更多。

## 4. 结论与建议

1. **打板路径关闭。** 12.5 个月的 min60 数据把 min5（1 个月）的结论放大并确认：触板即买 −0.45%/−0.61%/笔，封板后等开板 −1.04%/−1.29%/笔；正收益子集要么是事后信息（收盘封死），要么不可成交（一字板）。继续在日线/分钟线上找打板参数没有意义。
2. **连板≥3 接力仍是唯一幸存规则**，但 min60 封板质量不能稳定增强它。基线 +0.63%/笔、t=4.50；表现最好的 `open_limit` 和 `last_bar_vol_share` 都有样本选择、非单调或尾部依赖问题，且未通过同日配对/多重检验。
3. **不要切换现役模型，也不要为 daban 重训。** 模型在可执行样本上没有 edge，本次 min60 分析也没有给出可学习的标签/特征组合。
4. 唯一可做的是继续 **paper trade cb≥3 接力**（T+1 开盘买、T+1 收盘卖，开盘涨停放弃，单票≤10%，最多 3 只并发），至少 3 个月，记录真实滑点；若单笔净收益低于 +0.2%，停止。

## 6. 数据与偏差

- min60 覆盖 2025-09-05 ~ 2026-09-24；2026 年只到 9 月下旬，且只有约 12.5 个月、单一市场周期。
- 股票池为当前上市 A 股，存在退市/重组幸存者偏差；ST 用当前名称近似历史状态，5% 涨跌幅股票的历史 ST 身份可能有误。
- 触板即买假设涨停价能成交；封板后等开板假设开板时能按开盘价/涨停价成交。真实排队与冲击成本未实测，0.30% 双边成本可能偏乐观。
- 一字板按涨停价买入在多数情况下不可成交，文中已单独标注，未计入可执行结论。
