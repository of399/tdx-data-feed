# stage1 重训结论（结算内核改造后）

> 一次性研究快照，记录 2026-10-28 那一轮的口径变化与数字；不是现状规格。
> 结论：**保留新模型**（详见第 5 节）。新标签口径已写入 `AGENTS.md`「训练标签口径」。

## 1. 改了什么

| 项 | 旧口径 | 新口径 |
|---|---|---|
| 入场后第一根判定 | 入场根自身也算 | 入场次根才判定 |
| 同根双触发 | 止盈优先 | 止损优先 |
| 跳空穿越 | 按阈值价成交 | 按当日开盘成交 |
| 成本 | `gross − 2×(fee+slip)` 加法 | 内核 `CostModel.round_trip` 乘法 |

旧实现在同根双触发时默认止盈先成交，并把跳空穿越抹回阈值价，因此旧标签的收益分布被**系统性截断**在
`[-10%, +30%]`（旧标签实测 `min=-0.1026` / `max=0.2974`），新标签的尾部可以超出这个区间。

## 2. 样本边界（本轮先变的不是标签，是样本）

- 标签 CSV 仍 13064 行，但其中 **3083 行（bj 1539 + ETF 1544）在 `data/parquet/daily` 没有日线文件**，
  重算后为 null；宽表重装配按既有 `n_missing_file` 逻辑丢弃，**训练样本 13048 → 9981 行**。
- 依据：`full_sync` 自 2026-10-21 只同步沪深股票（`185deac`）；bj 缺口已于 2026-10-24 定案
  「只报告，不动策略口径」（`docs/PLAN_E_LIVE.md §4.2`）；`predict.py` 推理宇宙本就排除 bj/ETF。
- 这不是新缺陷，是训练宇宙对齐推理宇宙。若将来要覆盖 bj/ETF，先补历史数据再重跑本阶段。

两个数据事实（本阶段**未处置**，只披露，后续数据治理另开）：

1. **重复行**：标签 CSV 有 6 个 `(code, signal_date)` 键各 32 行、共 **192 行完全重复**（全部 30 列取值相同，
   round_trip 解析后逐列比对）。
   重算前既有（`_pre_settle_kernel_20261028/` 快照同样是 192 行 / 6 键），本阶段未增删行、未去重。
   其中 3 个键（`sh600375` 2006-11-16、`sh688409` 2023-03-22、`sz300377` 2024-09-26）标签非空，
   进入宽表后是 **96 行**，即 3 个样本在训练里被加权 32×；另外 3 个键是 bj/ETF，随缺日线一起被丢弃。
   这三条都早于 2025-01-01，**不进入 holdout 指标**，对第 4 节的对照无直接影响。
2. **两条极端新标签**（符合「跳空按开盘」裁决，不是缺陷）：
   - `sz000670` 2020-03-06 = **+466.6%**：hold 窗口内长期停牌后复牌直接跳空，穿越 +30% 按开盘成交；
   - `sz002041` 2015-06-03 = **−62.8%**：未复权除权缺口（59.98 → 23.88），穿越 −10% 按开盘成交。

   旧实现把这两类样本压成阈值本身（+29.74% / −10.26%）。两者都在 2025 年前，只进训练不进 holdout
   （Huber 目标对尾部不敏感，量级 2/9981 也可忽略）。

## 4. 重训结果

训练配置（`/tmp/stage1_retrain.log`、`logs/stage1_retrain_20261028_212922.json`）：

- 样本 9981 行（`hypothetical_pnl` 非空 9981 → 9981），特征 21 维（冻结契约未改），日期 1992-10-27 ~ 2026-09-22。
- holdout 选轮：train=7286 / valid(≥2025-01-01)=2695，`best_iteration = 117`，全量模型 117 棵树。
- `num_feature=21`，`feature_name()` 与 `data/double_up/stage1_selected_features.json` 的
  `selected_features` 逐字相同；`GATE_RESULT=RETRAIN_OK`。

| 口径 | n | Spearman | Top-10 PnL | Top-20 PnL | Top-50 PnL |
|---|---:|---:|---:|---:|---:|
| 纯 OOS（仅 <2025 训练，≥2025 测试） | 2695 | **0.2483** | 0.2853（胜率 0.90） | **0.2781**（胜率 0.90） | 0.2185（胜率 0.82） |
| holdout sanity（全量模型 on ≥2025，含 holdout，偏乐观） | 2695 | 0.4219 | 0.3364（胜率 1.00） | 0.3256（胜率 1.00） | 0.3061（胜率 0.98） |

「纯 OOS」是本轮唯一无泄漏的最近期估计；它只有 2025-01-01 一个 cutoff（`scripts/stage1_retrain.py`
当前不产出多折 walk-forward 表），所以「池化」= 该单折。「holdout sanity」列的新模型训练时看过 ≥2025，
早停轮数也在这段上选，双重乐观，**不能当效果证据**。

与闸门对照（`scripts/stage1_gate.py`：池化 Spearman ≥ 0.315 / Top-20 ≥ 0.21 / Top-50 ≥ 0.20）：

| 闸门 | 阈值 | 实际（纯 OOS，9981 行宇宙） | 是否过闸 |
|---|---:|---:|---|
| 池化 Spearman | 0.315 | 0.2483 | 否 |
| Top-20 均值 PnL | 0.21 | 0.2781 | 是 |
| Top-50 均值 PnL | 0.20 | 0.2185 | 是 |

闸门本身是在**旧宇宙（13048 行、含 bj/ETF）**上标定的，本轮宇宙只有 9981 行，绝对指标不可直接横比
（见第 5 节）。因此下面的匹配对照才是主判据。

### 匹配宇宙对照（Step 1b，主判据）

同一份新宽表、同一 holdout 窗口（≥2025-01-01，n=2695），分别给快照旧模型与重训新模型打分：

```
holdout n=2695 / total=9981
old: spearman=0.4025 top20_mean=0.3247 top20_win=1.000 top50_mean=0.3045 top50_win=1.000
new: spearman=0.4219 top20_mean=0.3256 top20_win=1.000 top50_mean=0.3061 top50_win=0.980
```

两者都受「训练时见过 ≥2025」的乐观偏差，但**偏差方向一致**，因此差值度量的是标签版本本身的影响：

| 指标 | old（旧标签训练） | new（新标签训练） | 差 |
|---|---:|---:|---:|
| Spearman | 0.4025 | 0.4219 | **+0.0194** |
| Top-20 均值 PnL | 0.3247 | 0.3256 | +0.0009 |
| Top-50 均值 PnL | 0.3045 | 0.3061 | +0.0016 |
| Top-20 胜率 | 1.000 | 1.000 | 0 |

注意：旧模型跑在**新标签**上的 0.4025 是污染值（它见过这些行的旧版标签），只能与同样见过 ≥2025 的
`new` / holdout sanity 比；历史上的 fold1≈0.3475 是旧标签上的读数，同属旧口径，**都不可与本轮纯 OOS
0.2483 并列**。

## 5. 决策

- **主判据**：Step 1b 的匹配对照——同一批 9981 行、同一 holdout 窗口下，新模型的 Spearman /
  Top-20 均值不低于旧模型。这是唯一同口径的比较。
- **参考**：`scripts/stage1_gate.py` 的闸门 0.315 / 0.21 / 0.20 是在旧宇宙（13048 行）上标定的，
  与新样本的绝对指标不可直接横比；只有「跌破闸门 **且** 同时低于旧模型」才构成回滚理由。

- [x] **保留新模型（匹配对照不劣于旧模型）**
- [ ] 回滚（匹配对照 Spearman 与 Top-20 同时明显更低）

**结论：保留新模型。** 四项匹配指标全部不劣于旧模型（Spearman 0.4025 → 0.4219，Top-20 0.3247 →
0.3256，Top-50 0.3045 → 0.3061，Top-20 胜率持平 1.000），不满足回滚条件。

纯 OOS Spearman 0.2483 跌破 0.315 闸门，但**不构成回滚理由**，两条理由都成立才算：

1. 匹配对照里新模型**高于**旧模型——口径换掉没有让模型变差，跌闸门不是新标签造成的；
2. 闸门是在 13048 行旧宇宙（含 bj/ETF）上标定的，样本换成 9981 行沪深股票后基线本身会移动，
   跨宇宙横比该阈值没有意义。

回滚路径保留备查（本轮**未执行**）：逐文件 `cp -p` 快照（只读模型要先替换）：

```bash
BK=data/double_up/_pre_settle_kernel_20261028
for f in d_signal_5d_features_vpnl.csv stage1_wide_table.parquet stage1_selected_features.json d_signal_5d_model_vpnl_huber_stage1.txt; do
  cp -p "$BK/$f" data/double_up/
done
# d_signal_5d_model_vpnl_huber.txt 是 444 只读，cp 到同名目标会 Permission denied
cp --remove-destination -p "$BK/d_signal_5d_model_vpnl_huber.txt" data/double_up/
```

回滚后逐文件 `md5sum -c` 对照 `$BK/MANIFEST.md`。

### 这个结论不覆盖什么

匹配对照只能证明「同一窗口内新标签产出的模型不劣于旧标签产出的模型」，**不能**证明新模型在干净未来
数据上能保持 0.4219 那档水平：两个模型都见过 ≥2025，0.4219 / 0.3256 都是偏乐观读数。唯一无泄漏的
数字是纯 OOS 0.2483 / 0.2781，而旧标签没有「仅 <2025 训练」的对应版本，做不出同口径的干净 OOS 对照。
后续若引用 stage1 的效果，请以 0.2483 / 0.2781 为准。

## 6. 下游影响

- `predict.py` 的模型**路径**没变（`data/double_up/d_signal_5d_model_vpnl_huber_stage1.txt`），换的是
  文件里的权重；因此预测分布会变（标签口径变了，模型学到的 PnL 尺度也变了）。
- 该模型在 `predict.py` 里的两个角色：`POSITION_MODE_MODEL["full"]`（大仓位、Top 20）与
  `FALLBACK_MODEL`（异常回退）。当前 `DEFAULT_POSITION_MODE = "small"` → 主流程默认走 `daban`，
  所以本轮切换不会改变默认输出，只改变 full 模式与回退路径上的打分。
- 历史报告（`data/plan_e/*.md`、`docs/stage1_optuna_report.md`、`docs/COMPARE_*` 等）是旧口径产物，
  引用时须注明标签版本；旧标签/旧模型的唯一权威副本在 `data/double_up/_pre_settle_kernel_20261028/`
  （gitignored，删了就没了）。
