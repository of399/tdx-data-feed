# stage1 重训结论（结算内核改造后）

> 一次性研究快照，记录 2026-10-28 那一轮的口径变化与数字；不是现状规格。
> 结论：**保留新模型**（主判据、辅判与代价见第 5 节）。新标签口径已写入 `AGENTS.md`「训练标签口径」。

## 1. 改了什么

| 项 | 旧口径 | 新口径 |
|---|---|---|
| 入场后第一根判定 | 入场根自身也算 | 入场次根才判定 |
| 同根双触发 | 止盈优先 | 止损优先 |
| 跳空穿越 | 按阈值价成交 | 按当日开盘成交 |
| 成本 | `gross − 2×(fee+slip)` 加法 | 内核 `CostModel.round_trip` 乘法 |

旧实现在同根双触发时默认止盈先成交，并把跳空穿越抹回阈值价，因此旧标签的收益分布被**系统性截断**在
`[-10%, +30%]`（旧标签实测 `min=-0.1026` / `max=0.2974`），新标签的尾部可以超出这个区间。

## 2. 样本边界（本轮先变的不是标签，是样本）

- 标签 CSV 仍 13064 行，但其中 **3083 行（bj 1539 + ETF 1544）在 `data/parquet/daily` 没有日线文件**，
  重算后为 null；宽表重装配按既有 `n_missing_file` 逻辑丢弃，**训练样本 13048 → 9981 行**。
- 依据：`full_sync` 自 2026-10-21 只同步沪深股票（`185deac`）；bj 缺口已于 2026-10-24 定案
  「只报告，不动策略口径」（`docs/PLAN_E_LIVE.md §4.2`）；`predict.py` 推理宇宙本就排除 bj/ETF。
- 这不是新缺陷，是训练宇宙对齐推理宇宙。若将来要覆盖 bj/ETF，先补历史数据再重跑本阶段。

两项数据事实（本阶段**未处置**，只披露，后续数据治理另开）：

1. **重复行**：标签 CSV 有 6 个 `(code, signal_date)` 键各 32 行、共 **192 行完全重复**（全部 30 列取值相同，
   round_trip 解析后逐列比对）。

   这三条都早于 2025-01-01，**不进入 holdout 指标**，对第 4 节的对照无直接影响。
2. **极端新标签**（符合「双触发结亏 / 跳空按开盘」裁决，不是缺陷）。宽表里 |PnL| 最大的五条：

   | `sz000670` | 2020-03-06 | **+466.6%**（4.6657） | hold 窗口内长期停牌后复牌直接跳空，穿越 +30% 按开盘成交 |

## 3. 标签分布

正收益率的定义是 `hypothetical_pnl > 0` 的行数 ÷ **`hypothetical_pnl` 非空行数**：

```
old（快照，旧口径）: 非空 13061 / 总行 13064，mean=0.1029 median=0.0561 pos=66.2%（8646/13061）min=-0.1026 max=0.2974
new（内核口径）    : 非空 9981 / 总行 13064（3083 行缺日线置空），mean=0.1171 median=0.0707 pos=68.0%（6785/9981）min=-0.6278 max=4.6657
```

上一版文档把 `new` 的正收益率写成 51.9%，那是 **6785/13064**——分母把 3083 个空值当成了负类，
是假象；非空分母下是 **68.0%**，与旧口径 66.2%（分母 13061）同量级。

注意宽表里另有一列 `is_positive`，它是信号生成阶段带下来的**分类标签**（与 `hypothetical_pnl > 0`
只有 71.9% 的行一致；9981 行上 5040/9981 = 50.5%），不是本节的收益率，也不能当胜率用。
本节与第 4 节所有正收益率均按 `hypothetical_pnl > 0` 计算。

两行样本集仍不同（`new` 少了缺日线的 3083 行，其中 bj 正样本占多数），所以全表 66.2% → 68.0%
**不构成升降结论**。去掉构成效应需要同集对照，按 `(code, signal_date)` 对齐，两种口径都做：

**主口径：行级对齐（9981 行）。** 两份 CSV 同源同序（13064 行逐行的 `code` / `signal_date`
已断言完全相同），取新标签非空的 9981 行，旧标签取同一批行：

```
rows=9981（含 3 个键各 32 行重复，即 96 行）
old: mean=0.1084 median=0.0709 pos=67.8%（6763/9981）
new: mean=0.1171 median=0.0707 pos=68.0%（6785/9981）
new<old 占 56.3%
```

**交叉核对：按键去重（9888 键）。** 两侧先 `drop_duplicates(["code", "signal_date"])` 再合并
（各 12878 键，其中新旧标签都非空 9888 键）：

```
keys=9888
old: mean=0.1081 median=0.0703 pos=67.5%（6670/9888）
new: mean=0.1168 median=0.0712 pos=67.7%（6692/9888）
new<old 占 56.2%
```

两种口径结论一致。**上一版的 12957 行是合并时未去重键造成的叉积假象，已作废**：CSV 侧有 6 个键
各 32 行、宽表侧有 3 个键各 32 行，`9981 + 2976 = 12957`，等于把 3 个样本按 32×32 加权。
在正确的同集对照下，标签口径改动基本不改分布形状（median 0.0709 → 0.0707、pos 67.8% → 68.0%），
mean 0.1084 → 0.1171 的抬升来自尾部放大（`min/max` 从 `-0.1026/+0.2974` 放宽到
`-0.6278/+4.6657`）。

## 4. 重训结果

训练配置（`logs/stage1_retrain_20261028_212922.{json,md,log}`）：

- 样本 9981 行（`hypothetical_pnl` 非空 9981 → 9981），特征 21 维（冻结契约未改），日期 1992-10-27 ~ 2026-09-22。
- holdout 选轮：train=7286 / valid(≥2025-01-01)=2695，`best_iteration = 117`，全量模型 **117 棵树**。
- 旧模型快照为 **132 棵树** / 21 维，特征名与冻结契约逐字相同（2026-10-28 回读核对）。
- `num_feature=21`，`feature_name()` 与 `data/double_up/stage1_selected_features.json` 的
  `selected_features` 逐字相同；`GATE_RESULT=RETRAIN_OK`。

| 口径 | n | Spearman | Top-10 PnL | Top-20 PnL | Top-50 PnL |
|---|---:|---:|---:|---:|---:|
| 纯 OOS（仅 <2025 训练，≥2025 测试） | 2695 | **0.2483** | 0.2853（胜率 0.90） | **0.2781**（胜率 0.90） | 0.2185（胜率 0.82） |
| holdout sanity（全量模型 on ≥2025，含 holdout，偏乐观） | 2695 | 0.4219 | 0.3364（胜率 1.00） | 0.3256（胜率 1.00） | 0.3061（胜率 0.98） |

「纯 OOS」只有 2025-01-01 一个 cutoff（`scripts/stage1_retrain.py` 当前不产出多折 walk-forward 表），
所以「池化」= 该单折。「holdout sanity」列的新模型训练时看过 ≥2025，早停轮数也在这段上选，
双重乐观，**不能当效果证据**。

### 与旧口径的同协议基线并置

同一脚本、同一协议（仅在 <2025 上训练，≥2025 打分，树数取该 holdout 上早停选出的轮数）
在旧标签/旧宇宙上的读数是 **Spearman 0.3475 / Top-20 0.2045**（13023 行、132 棵树、2026-10-10）。
2026-10-28 用快照宽表 + 冻结超参 + `n_estimators=132` 重跑，逐位复现了 0.3475 / 0.2045，
因此它是可复核的同协议读数，不是记忆值。

| 纯 OOS（同协议） | 时间 | 训练宇宙 | 树数 | 测试窗口 | Spearman | Top-20 PnL |
|---|---|---:|---:|---:|---:|---:|
| 旧标签 / 旧模型 | 2026-10-10 | 13023 行（含 bj/ETF） | 132 | ≥2025，n=4067 | **0.3475** | **0.2045** |
| 新标签 / 新模型 | 2026-10-28 | 9981 行（沪深） | 117 | ≥2025，n=2695 | **0.2483** | **0.2781** |
| 差（新 − 旧） | | −3042 行 | −15 棵 | −1372 行 | **−0.099** | **+0.0736** |

两轮的「纯 OOS」都不是完全干净的读数：树数是在**同一个 ≥2025 窗口**上早停选出来的
（`train_and_save`：先在 holdout 上 `early_stopping(50)` 得 `best_iteration`，再以该树数全量重训；
纯 OOS 那一份同样用这个树数在 <2025 上训练），所以测试窗口参与了「选几棵树」。
绝对水平因此偏乐观，做横比时只能看方向与量级。
另外两行测试窗口本身也不同（4067 含 bj/ETF，2695 只有沪深），宇宙、树数、标签口径
三个因素同时变了。

与闸门对照（`scripts/stage1_gate.py`：池化 Spearman ≥ 0.315 / Top-20 ≥ 0.21 / Top-50 ≥ 0.20）：

| 闸门 | 阈值 | 实际（纯 OOS，9981 行宇宙） | 是否过闸 |
|---|---:|---:|---|
| 池化 Spearman | 0.315 | 0.2483 | 否 |
| Top-20 均值 PnL | 0.21 | 0.2781 | 是 |
| Top-50 均值 PnL | 0.20 | 0.2185 | 是 |

闸门是在旧宇宙（13048 行、含 bj/ETF）上标定的。旧口径的同协议基线在 Spearman 上过闸
（0.3475 ≥ 0.315），Top-20 反而**不过闸**（0.2045 < 0.21）；本轮新模型 Spearman 跌破闸门
（0.2483），Top-20 / Top-50 转为过闸（0.2781 / 0.2185）。所以不能把 Spearman 的跌破解释成
「宇宙换了、基线自然漂移」——跌幅是真的，只是无法拆分到单一因素；经济口径则是**由不过闸改为过闸**。
下面的匹配对照才是主判据。

### 匹配宇宙对照（主判据）

同一份新宽表、同一 holdout 窗口（≥2025-01-01，n=2695），分别给快照旧模型与重训新模型打分：

```
holdout n=2695 / total=9981
old: spearman=0.4025 top20_mean=0.3247 top20_win=1.000 top50_mean=0.3045 top50_win=1.000
new: spearman=0.4219 top20_mean=0.3256 top20_win=1.000 top50_mean=0.3061 top50_win=0.980
```

| 指标 | old（旧标签训练） | new（新标签训练） | 差 |
|---|---:|---:|---:|
| Spearman | 0.4025 | 0.4219 | **+0.0194** |
| Top-20 均值 PnL | 0.3247 | 0.3256 | +0.0009 |
| Top-50 均值 PnL | 0.3045 | 0.3061 | +0.0016 |
| Top-20 胜率 | 1.000 | 1.000 | 0 |

读法：**方向性参考——同一份宽表与同一 holdout 上，新模型的样本外排序略优；但它不能隔离标签口径
的贡献。** 两个模型都见过 ≥2025（乐观偏差方向一致，这点成立），可训练侧同时有三处不同：
标签版本（本次改的）、训练宇宙（旧 13023 行含 bj/ETF vs 新 9981 行沪深）、
早停选出的树数（132 vs 117）。旧模型的 0.4025 也不可与上表的纯 OOS 0.2483 横比：
前者训练时看过 holdout，后者没有。

## 5. 决策

- **主判据：匹配宇宙对照四项不劣。** 同一批 9981 行、同一 holdout 下，Spearman 0.4025 → 0.4219、
  Top-20 0.3247 → 0.3256、Top-50 0.3045 → 0.3061、Top-20 胜率持平 1.000；回滚条件
  （Spearman 与 Top-20 同时明显更低）不成立。
- **辅判：同协议 Top-20 改善。** 旧 0.2045 → 新 0.2781（+0.0736），经济口径变好。
- **代价（同时列出，不藏）：**
  - 同协议纯 OOS Spearman **0.3475 → 0.2483（−0.099）**，跌破 0.315 闸门；
  - 训练宇宙从 13023 行缩到 9981 行（bj/ETF 缺日线被丢弃）；
  - 上面两项与标签口径三者混在一起，**无法把差值拆分到「标签口径」单一因素**上——宇宙与树数
    同时变了，本轮没有做二者固定、只换标签的消融。
- **结论：保留新模型。** 理由是主判据四项不劣 + 辅判 Top-20 改善；代价是纯 OOS Spearman 下降
  与宇宙缩小，二者均未归因。

- [x] **保留新模型（匹配对照不劣于旧模型，Top-20 同协议改善）**
- [ ] 回滚（匹配对照 Spearman 与 Top-20 同时明显更低）

### 这个结论不覆盖什么

匹配对照只能证明「同一窗口内新标签产出的模型四项指标不劣于旧标签产出的模型」，**不能**证明新模型
在干净未来数据上能保持 0.4219 那档水平：两个模型都见过 ≥2025，0.4219 / 0.3256 都是偏乐观读数。
同协议的干净 OOS 是新 0.2483 / 0.2781 对旧 0.3475 / 0.2045，其中 Spearman 掉了 0.099——
这是本轮**实际付出的代价**，不是噪声可忽略的差异，也没能归因。
后续引用 stage1 的效果时：新模型用 0.2483 / 0.2781，旧口径用 0.3475 / 0.2045，并注明宇宙与树数。

## 6. 下游影响

- `predict.py` 的模型**路径**没变（`data/double_up/d_signal_5d_model_vpnl_huber_stage1.txt`），换的是
  文件里的权重；因此预测分布会变（标签口径变了，模型学到的 PnL 尺度也变了）。
- 该模型在 `predict.py` 里的两个角色：`POSITION_MODE_MODEL["full"]`（大仓位、Top 20）与
  `FALLBACK_MODEL`（异常回退）。当前 `DEFAULT_POSITION_MODE = "small"` → 主流程默认走 `daban`，
  所以本轮切换不会改变默认输出，只改变 full 模式与回退路径上的打分。
- 历史报告（`data/plan_e/*.md`、`docs/stage1_optuna_report.md`、`docs/COMPARE_*` 等）是旧口径产物，
  引用时须注明标签版本；旧标签/旧模型的唯一权威副本在 `data/double_up/_pre_settle_kernel_20261028/`
  （gitignored，删了就没了）。
