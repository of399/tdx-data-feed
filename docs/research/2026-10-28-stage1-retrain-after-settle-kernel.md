# stage1 重训结论（结算内核改造后）

> 一次性研究快照，记录 2026-10-28 那一轮的口径变化与数字；不是现状规格。
> 结论：**保留新模型**（论证顺序与代价见第 5 节；标签归因以第 4 节同宇宙消融为准）。新标签口径已写入 `AGENTS.md`「训练标签口径」。

## 1. 改了什么

| 项 | 旧口径 | 新口径 |
|---|---|---|
| 入场后第一根判定 | 入场根自身也算 | 入场次根才判定 |
| 同根双触发 | 止盈优先 | 止损优先 |
| 跳空穿越 | 按阈值价成交 | 按当日开盘成交 |
| 成本 | `gross − 2×(fee+slip)` 加法 | 内核 `CostModel.round_trip` 乘法 |

旧实现在同根双触发时默认止盈先成交，并把跳空穿越抹回阈值价，因此旧标签的收益分布被**系统性截断**在
`[-10%, +30%]`（旧标签实测 `min=-0.1026` / `max=0.2974`），新标签的尾部可以超出这个区间。

## 2. 样本边界（本轮先变的不是标签，是样本）

- 标签 CSV 仍 13064 行，但其中 **3083 行（bj 1539 + ETF 1544）在 `data/parquet/daily` 没有日线文件**，
  重算后为 null；宽表重装配按既有 `n_missing_file` 逻辑丢弃，**训练样本 13048 → 9981 行**。
- 依据：`full_sync` 自 2026-10-21 只同步沪深股票（`185deac`）；bj 缺口已于 2026-10-24 定案
  「只报告，不动策略口径」（`docs/PLAN_E_LIVE.md §4.2`）；`predict.py` 推理宇宙本就排除 bj/ETF。
- 这不是新缺陷，是训练宇宙对齐推理宇宙。若将来要覆盖 bj/ETF，先补历史数据再重跑本阶段。

## 3. 标签分布

正收益率的定义是 `hypothetical_pnl > 0` 的行数 ÷ **`hypothetical_pnl` 非空行数**：

```
old（快照，旧口径）: 非空 13061 / 总行 13064，mean=0.1029 median=0.0561 pos=66.2%（8646/13061）min=-0.1026 max=0.2974
new（内核口径）    : 非空 9981 / 总行 13064（3083 行缺日线置空），mean=0.1171 median=0.0707 pos=68.0%（6785/9981）min=-0.6278 max=4.6657
```

上一版文档把 `new` 的正收益率写成 51.9%，那是 **6785/13064**——分母把 3083 个空值当成了负类，
是假象；非空分母下是 **68.0%**，与旧口径 66.2%（分母 13061）同量级。

注意宽表里另有一列 `is_positive`，它是信号生成阶段带下来的**分类标签**（与 `hypothetical_pnl > 0`
只有 71.9% 的行一致；9981 行上 5040/9981 = 50.5%），不是本节的收益率，也不能当胜率用。
本节与第 4 节所有正收益率均按 `hypothetical_pnl > 0` 计算。

两行样本集仍不同（`new` 少了缺日线的 3083 行，其中 bj 正样本占多数），所以全表 66.2% → 68.0%
**不构成升降结论**。去掉构成效应需要同集对照，按 `(code, signal_date)` 对齐，两种口径都做：

**主口径：行级对齐（9981 行）。** 两份 CSV 同源同序（13064 行逐行的 `code` / `signal_date`
已断言完全相同），取新标签非空的 9981 行，旧标签取同一批行：

```
rows=9981（含 3 个键各 32 行重复，即 96 行）
old: mean=0.1084 median=0.0709 pos=67.8%（6763/9981）
new: mean=0.1171 median=0.0707 pos=68.0%（6785/9981）
new<old 占 56.3%
```

**交叉核对：按键去重（9888 键）。** 两侧先 `drop_duplicates(["code", "signal_date"])` 再合并
（各 12878 键，其中新旧标签都非空 9888 键）：

```
keys=9888
old: mean=0.1081 median=0.0703 pos=67.5%（6670/9888）
new: mean=0.1168 median=0.0712 pos=67.7%（6692/9888）
new<old 占 56.2%
```

两种口径结论一致。**上一版的 12957 行是合并时未去重键造成的叉积假象，已作废**：CSV 侧有 6 个键
各 32 行、宽表侧有 3 个键各 32 行，`9981 + 2976 = 12957`，等于把 3 个样本按 32×32 加权。
在正确的同集对照下，标签口径改动基本不改分布形状（median 0.0709 → 0.0707、pos 67.8% → 68.0%），
mean 0.1084 → 0.1171 的抬升来自尾部放大（`min/max` 从 `-0.1026/+0.2974` 放宽到
`-0.6278/+4.6657`）。

## 4. 重训结果

训练配置（`logs/stage1_retrain_20261028_212922.{json,md,log}`）：

- 样本 9981 行（`hypothetical_pnl` 非空 9981 → 9981），特征 21 维（冻结契约未改），日期 1992-10-27 ~ 2026-09-22。
- holdout 选轮：train=7286 / valid(≥2025-01-01)=2695，`best_iteration = 117`，全量模型 **117 棵树**。
- 旧模型快照为 **132 棵树** / 21 维，特征名与冻结契约逐字相同（2026-10-28 回读核对）。
- `num_feature=21`，`feature_name()` 与 `data/double_up/stage1_selected_features.json` 的
  `selected_features` 逐字相同；`GATE_RESULT=RETRAIN_OK`。

| 口径 | n | Spearman | Top-10 PnL | Top-20 PnL | Top-50 PnL |
|---|---:|---:|---:|---:|---:|
| 纯 OOS（仅 <2025 训练，≥2025 测试） | 2695 | **0.2483** | 0.2853（胜率 0.90） | **0.2781**（胜率 0.90） | 0.2185（胜率 0.82） |
| holdout sanity（全量模型 on ≥2025，含 holdout，偏乐观） | 2695 | 0.4219 | 0.3364（胜率 1.00） | 0.3256（胜率 1.00） | 0.3061（胜率 0.98） |

「纯 OOS」只有 2025-01-01 一个 cutoff（`scripts/stage1_retrain.py` 当前不产出多折 walk-forward 表），
所以「池化」= 该单折。「holdout sanity」列的新模型训练时看过 ≥2025，早停轮数也在这段上选，
双重乐观，**不能当效果证据**。

### 与旧口径的同协议基线并置

同一脚本、同一协议（仅在 <2025 上训练，≥2025 打分，树数取该 holdout 上早停选出的轮数）
在旧标签/旧宇宙上的读数是 **Spearman 0.3475 / Top-20 0.2045**（13023 行、132 棵树、2026-10-10）。
2026-10-28 用快照宽表 + 冻结超参 + `n_estimators=132` 重跑，逐位复现了 0.3475 / 0.2045，
因此它是可复核的同协议读数，不是记忆值。

| 纯 OOS（同协议） | 时间 | 训练宇宙 | 树数 | 测试窗口 | Spearman | Top-20 PnL |
|---|---|---:|---:|---:|---:|---:|
| 旧标签 / 旧模型 | 2026-10-10 | 13023 行（含 bj/ETF） | 132 | ≥2025，n=4067 | **0.3475** | **0.2045** |
| 新标签 / 新模型 | 2026-10-28 | 9981 行（沪深） | 117 | ≥2025，n=2695 | **0.2483** | **0.2781** |
| 差（新 − 旧） | | −3042 行 | −15 棵 | −1372 行 | **−0.099** | **+0.0736** |

两轮的「纯 OOS」都不是完全干净的读数：树数是在**同一个 ≥2025 窗口**上早停选出来的
（`train_and_save`：先在 holdout 上 `early_stopping(50)` 得 `best_iteration`，再以该树数全量重训；
纯 OOS 那一份同样用这个树数在 <2025 上训练），所以测试窗口参与了「选几棵树」。
绝对水平因此偏乐观，做横比时只能看方向与量级。
另外两行测试窗口本身也不同（4067 含 bj/ETF，2695 只有沪深），宇宙、树数、标签口径
三个因素同时变了。

### 同宇宙、只换标签的消融（本轮补做）

上一版说「无法把差值拆分到标签口径、需先补 bj/ETF 历史日线」——这不成立。用现成的 9981 行宽表
+ 快照旧标签，固定特征（21 维）、超参、时间切分（仅 <2025 训练、≥2025 打分）与树数，
只换标签列即可做消融；不需要 bj/ETF 的历史日线，那是宇宙问题、不是归因问题。
旧标签按 `(code, signal_date)` 去重后 left-merge 到宽表，缺 0 行。

| 口径 | 训练宇宙 | 标签 | 树数 | Spearman | Top-20 | Top-50 |
|---|---|---|---:|---:|---:|---:|
| v1 基线（2026-10-10，2026-10-28 逐位复现） | 13023（含 bj/ETF） | 旧 | 132 | 0.3475 | 0.2045 | — |
| 旧标签 / 新宇宙 | 9981 | 旧 | 132 | 0.2594 | 0.2890 | 0.2136 |

| 新标签 / 新宇宙 | 9981 | 新 | 117 | 0.2483 | 0.2781 | 0.2185 |
| 新标签 / 新宇宙 | 9981 | 新 | 132 | 0.2477 | 0.2788 | 0.2129 |

以 132 棵树为同树数对照，总差可逐项相加：

- **宇宙效应**（13023 含 bj/ETF → 9981 沪深，同为旧标签、132 棵树）：
  Spearman **−0.0881**（0.2594 − 0.3475）、Top-20 **+0.0845**（0.2890 − 0.2045）；
- **标签效应**（同 9981 宇宙、同 132 棵树，旧标签 → 新标签）：
  Spearman **−0.0117**（0.2477 − 0.2594）、Top-20 **−0.0102**（0.2788 − 0.2890）；
- 两者相加 = **−0.0998 / +0.0743**，与 132 棵树下的观测总差同值。**分解只在固定的 132 棵树下成立**：
  117 棵树的总差是 −0.0992 / +0.0736，跨树数不要把标签效应加回总差。
- 117 棵树下的标签效应：Spearman **−0.0123**（0.2483 − 0.2606）、Top-20 **+0.0007**（0.2781 − 0.2774）。

读法：**Spearman 跌破 0.315 闸门主要是宇宙收缩造成的，换标签本身只值约 −0.012**；Top-20 的抬升
也主要来自宇宙（+0.08），标签效应在 ±0.01 量级。**单折、树数固定、无显著性检验，只作方向与量级参考。**

复跑（本表四行消融读数由此脚本产出，与表内数字逐位一致；v1 基线行由 `load_and_validate` 同一路径复现）：

```python
import json, sys
from pathlib import Path
sys.path.insert(0, "scripts")
import lightgbm as lgb, numpy as np, pandas as pd
from stage1_baseline import _eval_fold, DEFAULT_LGBM

cfg = json.loads(Path("data/double_up/stage1_selected_features.json").read_text())
feats, hp = cfg["selected_features"], cfg["hyperparams"]
w = pd.read_parquet("data/double_up/stage1_wide_table.parquet")
w["code"] = w["code"].astype(str).str.zfill(6); w["signal_date"] = w["signal_date"].astype(str)
old = pd.read_csv("data/double_up/_pre_settle_kernel_20261028/d_signal_5d_features_vpnl.csv",
                  usecols=["code", "signal_date", "hypothetical_pnl"], float_precision="round_trip")
old["code"] = old["code"].astype(str).str.zfill(6); old["signal_date"] = old["signal_date"].astype(str)
old = old.drop_duplicates(["code", "signal_date"]).rename(columns={"hypothetical_pnl": "pnl_old"})
d = w[["code", "signal_date"] + feats + ["hypothetical_pnl"]].merge(old, on=["code", "signal_date"], how="left")
dates = pd.to_datetime(d["signal_date"]).values
tr, va = dates < np.datetime64("2025-01-01"), dates >= np.datetime64("2025-01-01")
X = d[feats].astype(float)
def run(ycol, tag, trees):
    p = dict(DEFAULT_LGBM); p.update(hp); p.update(objective="huber", alpha=0.5, random_state=42, n_estimators=trees)
    m = lgb.LGBMRegressor(**p).fit(X[tr], d.loc[tr, ycol].astype(float))
    r = _eval_fold(d.loc[va, ycol].astype(float).values, m.predict(X[va]), [20, 50])
    print(f"{tag} trees={trees}: spearman={r['spearman']:.4f} top20={r['top'][20]['mean_pnl']:.4f} top50={r['top'][50]['mean_pnl']:.4f}")
for trees in (117, 132):
    run("hypothetical_pnl", "NEW-label", trees)
    run("pnl_old", "OLD-label", trees)
```

与闸门对照（`scripts/stage1_gate.py`：池化 Spearman ≥ 0.315 / Top-20 ≥ 0.21 / Top-50 ≥ 0.20）：

| 闸门 | 阈值 | 实际（纯 OOS，9981 行宇宙） | 是否过闸 |
|---|---:|---:|---|
| 池化 Spearman | 0.315 | 0.2483 | 否 |
| Top-20 均值 PnL | 0.21 | 0.2781 | 是 |
| Top-50 均值 PnL | 0.20 | 0.2185 | 是 |

闸门是在旧宇宙（宽表 13048 行，有效样本 13023 行、含 bj/ETF）上标定的。旧口径的同协议基线在
Spearman 上过闸（0.3475 ≥ 0.315），Top-20 反而**不过闸**（0.2045 < 0.21）；本轮新模型 Spearman
跌破闸门（0.2483），Top-20 / Top-50 转为过闸（0.2781 / 0.2185）。

跌破要按上一子节拆开看：**跌幅主要来自宇宙收缩（−0.0881），换标签本身只占约 −0.012**，
经济口径的抬升（Top-20 0.2045 → 0.2781）同样主要来自宇宙（+0.0845）。更关键的是，**旧标签在
新宇宙上同样只有 0.2594（132 棵树）/ 0.2606（117 棵树），也过不了 0.315 闸门**——该闸门在当前宇宙上
对任何标签版本都不成立，必须按新宇宙重新标定。这不是本轮可以「调阈值」蒙过去的事：改阈值要另立协议、
保留旧宇宙对照，并说明新阈值的经济含义。下面的匹配对照降为一致性 sanity，主判据是上一子节的消融分解。

|---|---:|---:|---:|

新模型在全量 9981 行（含 ≥2025）上重训，见过的正是被评分的新标签；旧模型只在同一批日期上
见过**旧标签**，却拿新标签度量。优势方向固定偏向新模型，所以这组数字只能排除「大幅退化」，
不能证明新标签更好——即便四项全平，也不能作为升级依据。主判据是上一子节「同宇宙、只换标签」
的消融分解（固定宇宙与树数，只换标签列）。

可训练侧的另外两处差异（宇宙 13023 含 bj/ETF vs 9981 沪深、早停树数 132 vs 117）已在上一子节
单独量化，不再混在这组读数里。旧模型的 0.4025 也不可与上表的纯 OOS 0.2483 横比：
前者训练时看过 holdout，后者没有。

## 5. 决策

论证顺序按重要性排：

1. **正确性优先（不依赖任何指标）。** 新标签是内核裁决的产物：同一根 K 线双触发结算亏损侧、
   跳空穿越按当日开盘成交、入场次根起判定。回滚等于恢复一个**已知错误**的标签定义——
   旧口径把双触发默认记成止盈、把跳空抹回阈值价，收益分布被系统性截断在 `[-10%, +30%]`。
   这一条不因闸门或指标读数而改变。**并且保留新标签就必然重训**：模型学的是标签的尺度与分布，
   在已换标签的数据上继续用旧模型打分没有意义；`predict.py` 的 `prob = model.predict(...)` 与
   `--threshold` / `--emit-threshold` 都是对**预测 PnL 的绝对阈值**，模型与标签尺度必须成对。
   所以「保留新标签」落地就是「保留按新标签重训的模型」。
2. **代价已量化。** 同宇宙、同协议、只换标签：Spearman 效应 ≈ **−0.012**（132 棵树 −0.0117 /
   117 棵树 −0.0123）、Top-20 效应 ≈ **±0.01**（−0.0102 / +0.0007）。单折、树数固定、无显著性检验，
   属噪声量级。
3. **闸门跌破的主因不是标签，是宇宙。** 宇宙收缩贡献 Spearman **−0.0881**、Top-20 **+0.0845**；
   且旧标签在新宇宙上同样只有 0.2594 / 0.2606，**也过不了 0.315 闸门**——闸门对当前宇宙上任何
   标签版本都不成立，要重新标定，不能靠调阈值蒙过去。

   偏向新模型），主判据改为同宇宙消融分解 + 正确性优先；匹配对照降为一致性 sanity。

- 本轮只有单折、单 seed，没有显著性检验。

- [x] **保留新模型（正确性优先；标签效应在噪声量级；闸门跌破归因于宇宙收缩）**

## 6. 下游影响

- `predict.py` 的模型**路径**没变（`data/double_up/d_signal_5d_model_vpnl_huber_stage1.txt`），换的是
  文件里的权重；因此预测分布会变（标签口径变了，模型学到的 PnL 尺度也变了）。
- **规格偏差**：规格阶段 3 要求标签写 `d_signal_5d_features_vpnl_v2.csv`、模型写 `..._stage1_v2.txt`
  （旧文件不动），实际做的是**就地重写**同名 CSV / 宽表 / 模型，前置
  `data/double_up/_pre_settle_kernel_20261028/` 五件套快照 + md5 + 一键回滚。理由：下游
  （`stage1_wide_table`、`predict.py`、报告）都按单一路径读，v2 文件名要求把新路径参数穿到每一处；
  回滚安全性由快照保证。差异已记入规格「实施期更正（阶段 2，2026-10-28）」。
- 该模型在 `predict.py` 里的两个角色：`POSITION_MODE_MODEL["full"]`（大仓位、Top 20）与
  `FALLBACK_MODEL`（异常回退）。当前 `DEFAULT_POSITION_MODE = "small"` → 主流程默认走 `daban`，
  所以本轮切换不会改变默认输出，只改变 full 模式与回退路径上的打分。
- 预测值的量级没变（宽表上：旧模型 0.018–0.250、新模型 0.003–0.285），`predict.py` 默认
  `--threshold 0.7` / `--emit-threshold 0.7` 在两版模型上都不会触发，所以默认选股数不受影响。
  但**不要跨版本比较 prob 的具体数值**：标签尺度变了（旧标签被截断在 `[-10%, +30%]`，新标签
  尾部可到 +466%），同一个 prob 在两版模型里含义不同。
- 历史报告（`data/plan_e/*.md`、`docs/stage1_optuna_report.md`、`docs/COMPARE_*` 等）是旧口径产物，
  引用时须注明标签版本；旧标签/旧模型的唯一权威副本在 `data/double_up/_pre_settle_kernel_20261028/`
  （gitignored，删了就没了）。
