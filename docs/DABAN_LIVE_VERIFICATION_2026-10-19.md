## 1. 双轨对照设计

| 轨 | 模型 | 目标 | 角色 |
|---|---|---|---|
| 实验轨 | **daban** | 二分类：次日收盘涨停 | 待验证 |
| 对照轨 | `vpnl_huber_stage1` | 回归：数日波段 PnL | 现役基准 |

**核对指标**：Top-N 推荐股在**验证日**的实际涨停命中率 + 平均涨幅。

### 时间线说明（重要）

`daban` 的标签定义为  `close[T+1]/close[T] - 1 >= limit`：

| 概念 | 日期（本次）| 说明 |
|---|---|---|
| 特征日 T | 2026-10-16（周五收盘）| 数据最新日 |
| **验证日 T+1** | **2026-10-19（周一）** | 「次日涨停」实际发生日 |
| 可核对时点 | 2026-10-20 及之后 | 需等 10-19 收盘数据同步 |

**因此**：10-19 是第 1 个验证日；10-20 起可核对命中率。

## 2. 每日流程

```bash
# 1) 收盘后生成双轨清单（分别在 15:00 数据同步后跑）
venv/bin/python scripts/predict.py --model daban  --top 20 --features polars
venv/bin/python scripts/predict.py --model vpnl_huber_stage1 --top 20 --features polars

# 2) 整理为当日 track 记录（脚本/手工均可，格式见下）
#    data/predictions/verify/track_YYYYMMDD.csv

# 3) 次日核对命中率
venv/bin/python scripts/verify_daban_hit.py --track data/predictions/verify/track_YYYYMMDD.csv
```

### track CSV 字段

| 字段 | 说明 |
|---|---|
| `date` | 验证日（即 T+1，实际涨停发生日）|
| `model` | `daban` / `stage1` |
| `rank` | Top 排序 |
| `code` / `name` | 股票代码 / 名称 |
| `prob` | 模型打分（daban=涨停概率；stage1=PnL 预测值）|
| `close` | 特征日收盘价 |
| `consec` | 连板数（**风险分层用**：首板风险低、高位板风险高）|
| `is_limit` | 特征日是否收盘涨停 |

## 3.5 命中率与 Top N 的关系（决定清单档位）

回测口径：333 个交易日 / 132,421 条样本 / 自然涨停率 **1.50%**。

| Top N | daban 命中率 | stage1 命中率 | 提升 | 倍数 |
|---:|---:|---:|---:|---:|
| 1 | **27.93%** | 13.51% | +14.4pp | **2.07×** |
| 3 | 23.02% | 12.01% | +11.0pp | 1.92× |
| **5（本方案采用）** | **19.94%** | 10.69% | +9.3pp | 1.87× |
| 10 | 15.20% | 9.85% | +5.4pp | 1.54× |
| 20 | 10.96% | 7.91% | +3.1pp | 1.39× |
| 50 | 6.79% | 5.56% | +1.2pp | 1.22× |

**结论**：命中率随 Top N 缩小而**单调大幅提升**。本方案采用 **Top 5**（命中率约 20%，每日 5 只，兼顾命中率与机会数）。

**权衡提醒**：命中率 ↑ ≠ 总收益 ↑。实盘应最大化
`期望收益 = 命中率 × 平均盈利 − (1−命中率) × 平均亏损`。
先用 Top 5 验证 2-4 周，再按实际盈亏决定收缩或放开。

**进一步提命中率的路径（按 ROI）**：

| 优先级 | 路径 | 是否需重训 | 对命中率影响 |
|---|---|---|---|
| P0 | 缩小 Top N（已采用 Top 5）| 否（零风险）| 显著提升 |
| P1 | 标签精化：改为「能获利了结的涨停」| 是 | 统计命中率或降，但实盘盈利能力升 |
| P1 | 特征增强：板块联动 / 市场情绪 / 资金流 | 是 | 中高 |
| P2 | 概率校准（先验修正）| 否 | **不改排序 → 不提升命中率** |
| P2 | 调参 / 集成 | 是 | 边际递减 |

## 4. 决策标准（2-4 周后）

| 情形 | 决策 |
|---|---|
| `daban` 命中率 **≥** `stage1`，且平均涨幅不显著更差 | ✅ **切换**：`DEFAULT_MODEL` 改为 `daban` |
| `daban` 命中率 **明显低于** `stage1` | ❌ 维持现役，重新审视回测口径 |
| 样本不足（累计 < 15 个交易日）| ⏳ 延长验证，不做决策 |

**建议最低样本**：累计 ≥ 15 个交易日（约 3 周）再决策，避免单日噪声。

## 5. 已知限制

1. **数据延迟**：推荐基于上一交易日收盘（T），验证日（T+1）数据需等收盘后同步。
2. **实时行情不可用**：2026-10-19 尝试 akshare 东财/新浪接口均失败，无法盘中确认一字板（买不进）。
3. **模型给高位板高分**：如 600825（11 连板）仍获 `daban` 0.9332 —— 模型只看统计规律，**实盘必须叠加连板过滤**（高位板不追）。
4. **未含交易成本**：命中率不含手续费/滑点/一字板无法成交的摩擦。
