# 模型迭代优先级计划（daban 打板信号模型）

- 制定日期：2026-10-20
- 现役模型：`data/double_up/d_signal_5d_model_daban.txt`（LightGBM，29 维，标签 y = T+1 收盘涨停）
- 现役基线：OOS AUC **0.8090**；Top5 命中率 2025 **24.52%** / 2026 **21.70%**（`docs/MODEL_SWITCH_DABAN_2026-10-19.md`）
- 训练成本实测：**约 17 min**（`compare_daban_vs_stage1.py` 头注实证）
- 固定口径（对比必须一致）：`SPLIT_DATE=2025-06-01`、`RANDOM_SEED=42`、`NEG_RATIO=5`、剔除 T 日开盘即涨停样本

---

## 排序原则

投入成本 ↑、预期边际收益 ↓ 的对照：

| 阶段 | 投入 | 预期收益 | 依赖 |
|---|---|---|---|
| 0 盘中硬过滤 | 0 训练 | +0.37pp/笔（已验证） | 无 |
| 1 标签可诊断性 | 分钟级（抽样评估） | 决定要不要投阶段 2 | 无 |
| 2 标签口径 A/B 重训 | 改码 + 2×17min | 修标签-收益错配 | 阶段 1 结论 |
| 3 Sec 特征化 | 改特征管线 + 全量重训 | 小（过滤已吃掉大部分） | 阶段 2 结论 + T-1 口径 |
| 4 v9r LLM 线 | — | 0（已判定失败） | 不排期 |

---

## 阶段 0（立即）— 盘中板块硬过滤

- **动作**：打板决策前加"板块强度 + 板块共振"双重门槛
- **命令**：`venv/bin/python scripts/daban_scan.py --min-sector-sec 60 --min-sector-limitup 2`
- **需否重训**：否
- **预期收益**：保留 19% 交易，均收益 1.622% → **1.994%**（+23%）；胜率 62.5% → 65.8%；各年回撤均改善
- **依据**：`scripts/daban_sec_ablation.py`（89,474 笔，命中 98.6%），分年 6/7 正向（2024 微负 -0.06）
- **落点**：**只加在扫描器（盘中实时确认）**。当日板块涨停家数/涨幅排名是 T 日收盘后才知道，**不可用于 T-1 盘前候选池**（那是泄漏）

## 阶段 1（其次）— 标签可诊断性（不训练，先探路）

- **动作**：在统一评估集上，比较「T+1 收盘涨停」与「T+1 开盘溢价>0」两个标签下的**可预测性**；先不重训，用现役 29 维特征 + 小样本 LGB 跑诊断
- **命令**：`venv/bin/python scripts/compare_daban_vs_stage1.py --limit 150 --recent 300`（抽样式评估，分钟级）
- **需否重训**：否（诊断用小模型）
- **预期收益**：0（本身不计收益），产出是**是否值得投阶段 2 的判断依据**
- **依据/门槛**：若「隔夜溢价」标签下 AUC 显著低于现役标签（如 < 0.55），说明该目标更弱 → 阶段 2 降级为"多任务"或改样本空间而非改标签
- **必须先于阶段 2**：两个变体各要 17 min 训练 + 评估，若阶段 1 已判定某变体无希望，就省掉整轮训练

## 阶段 2（其次，依赖阶段 1 结论）— 标签口径 A/B 重训

- **对比对象**（一次只改一个变量）：
  - 变体 A：标签 = T+1 收盘涨停，样本空间 = 全市场日频（**现役基线**）
  - 变体 B：标签 = T+1 开盘溢价 > 0，样本空间 = **T 日封板样本**（打板真实可交易集）
- **改动点**：`scripts/train_daban_model.py` 新增 `--label-mode {close_limit|open_premium}` 与 `--sample-space {all|limit_up}`（`build_dataset()` 第 108 行标签判定 + 正负采样处）
- **命令**：
  ```
  venv/bin/python scripts/train_daban_model.py --tag label_b
  venv/bin/python scripts/compare_daban_vs_stage1.py --limit 300 --recent 500
  ```
- **需否重训**：是（变体 B 一次；变体 A 用现役模型文件，不重复训练）
- **评估指标（关键：跨标签不可直接比 AUC/命中率）**：
  - 统一评估集 = 变体 B 的样本空间，**统一评估标签 = T+1 开盘卖出净收益 > 0**
  - 两个模型都在这个评估集上算：OOS AUC（排序能力）+ Top5 命中率（Top5 中正标签占比）
  - 另附各模型在自身训练标签下的 AUC（仅作参考，不横向比）
- **产出隔离（硬要求）**：
  - 训练必须带 `--tag label_b` → 产出 `d_signal_5d_model_daban_label_b.txt` + `daban_train_report_label_b.md`
  - **禁止空 tag 覆盖现役** `d_signal_5d_model_daban.txt`；训练前先备份 `d_signal_5d_model_daban.txt` → `.bak_YYYYMMDD.txt`
  - 推理验证用 `predict.py --model daban_label_b` 或 `TDX_MODEL=daban_label_b`，**验收前不改 DEFAULT_MODEL**
  - 现役 canary（模型文件存在性 → 自动回退 stage1）保持生效
- **预期收益**：修掉"模型学的（T+1 收盘涨停）≠ 策略赚的（T+1 开盘卖）"的错配；Top5 命中率若从 21.70% → ≥23.7%（+2pp）即达标
- **门槛**：OOS AUC ≥ 0.799（现役 0.809 不退 0.01）且 Top5 命中率 +2pp，两条同时满足才进入阶段 3

## 阶段 3（最后，依赖阶段 2 结论）— Sec 特征化

- **前置依赖**（缺一不可）：
  1. 阶段 2 已定标签与样本空间（否则特征管线的目标会再变一次）
  2. **T-1 口径**的板块特征就绪：训练可用同日 sec（信号日 T 收盘决策 → T+1 收益，合法），但**盘前推理只能用 T-1 的值** → 必须构造 `sec_lag1 / sector_pct_lag1 / sector_limitup_lag1`（滞后一版），并做训练侧-推理侧同源校验
  3. 已有 `data/factors/sector_features.{csv,parquet}`（503,712 行 × 1,644 日）可直接 join
- **改动点**：`tdxfeed/features_5d.py` 扩展 + `scripts/predict.py` 特征列同步（两侧必须同源，参照 D.1 的 qfq 分布漂移教训）
- **命令**：`venv/bin/python scripts/train_daban_model.py --tag sec_lag1`
- **需否重训**：是（全量，维度变化 → 权重不兼容）
- **预期收益（诚实偏低）**：**小**。Sec 的增益已被阶段 0 的推理期过滤吃掉（+0.37pp/笔），且与已有 `ind_ret_5d_avg / ind_pct_t1_avg / ind_stock_count / consecutive_boards` 部分重叠。特征化的真正增量在于"**盘前也可用**"（T-1 Sec 进 predict.py 出候选池）
- **决策门槛**：只有当阶段 2 达标 **且** 阶段 3 在统一评估集上 Top5 命中率相对阶段 2 的变体再 +1pp 以上，才保留；否则回退到"只用阶段 0 过滤"
- **风险**：特征维度变化要求全量重训；Sec 与"身位/行业动量"重叠可能无增量；任何 T-1 口径错误 = 未来信息泄漏

## 阶段 4（不排期）— v9r LLM 线

- 已判定失败：ckpt-1000 direction_acc 0.0333（早停线 0.20）、spearman 0.0000、91% flat；loss step500→1100 仅降 0.011 → 训练动力学失败，训到 2000 步亦无改变
- 不在生产链路（`predict.py` 默认 = daban），任务目标（涨/跌/震三分类）与打板决策错配
- 仅当重新定义任务（如让 LLM 做候选复核/复述而非分类）时才重启，且需单独立项

---

## 为何必须按此顺序

1. **阶段 0 先行**：零训练成本、结论已由 7 年回测支撑，先落袋；同时它改变后续所有实验的样本口径（过滤后子集），后续评估都应在该子集上做
2. **阶段 1 必须先于阶段 2**：阶段 2 每个变体 = 改码 + 17 min 训练 + 评估。阶段 1 用分钟级诊断就能判定"哪个标签值得训"，避免白跑整轮
3. **阶段 2 必须先于阶段 3**：两个变体必须**一次只改一个变量**。同时改标签与加特征将无法归因增益来源（历史上 D.3.1 的教训就是过滤器贡献了绝大部分收益）
4. **阶段 3 放最后**：特征化是"锦上添花"而非"补漏"，且引入 train/serve 口径不一致的风险；先用过滤拿到大部分收益，再用 T-1 口径把 Sec 送进盘前，收益/风险比才划算

## 隔离要求汇总

| 项 | 要求 |
|---|---|
| 训练输出 | 一律 `--tag <name>`；空 tag = 覆盖现役，**禁止** |
| 现役备份 | 每次重训前 `d_signal_5d_model_daban.txt` → `.bak_YYYYMMDD.txt` |
| 推理验证 | `predict.py --model <tag>` / `TDX_MODEL=<tag>`；不改 DEFAULT_MODEL 直到验收通过 |
| 评估可比 | SPLIT_DATE / seed / NEG_RATIO / 剔除开盘涨停样本 四项与现役一致 |
| 跨标签比较 | 必须统一评估集 + 统一评估标签，否则 AUC/命中率不可比 |
| 报告 | 每个 tag 产出独立 `daban_train_report_<tag>.md` |
