# DABAN cb≥3 接力纸盘交易规则清单

> 版本：v1.0（2026-10-22）
> 状态：**仅纸盘**，不接实盘资金。
> 依据：`DABAN_SALVAGE_20261022.md` 3.1–3.10、`DABAN_MIN60_EXEC_20261022.md` Part B。
> 规则一旦开跑即冻结；任何参数改动都视为新实验，重新计时。

> **⚠️ 开跑前必读（2026-10-22 回放结果）**
> 用本清单的诚实执行规则回放 2025-09-05 ~ 2026-09-24（12.5 个月），Book B 为 **1,017 笔 / 251 天，`net_fixed` −0.903%/笔，t=−1.82**，已低于第 8.2 节的 **+0.20% 停止线**；Book A 为 **−22.22%**，最大回撤 **−34.63%**。
> 与旧基线 +0.633%/笔的差异不是模拟器误差，而是两类真实损失：跌停顺延 162 笔（−11.20%/笔）和回测闸门丢弃的异常价 70 笔（−12.03%/笔）。非顺延子集仍为 **+1.048%/笔**（855 笔）。
> 同一规则在 6.7 年全历史（5,972 笔）按本清单回放为 **−0.362%/笔，日度 t=−1.05**；932 笔（15.61%）T+1 收盘跌停。旧报告的 +0.39% 只识别了 273 笔（4.57%）顺延，低估约 3.4 倍。
> 因此，**按现有证据，这个实验开跑后的第一项结论很可能是触发停止线**。开跑应定位为"用实时数据证伪/确认 −0.90% 的回放结论"，而不是一个有望盈利的策略；若不能接受这一点，应直接不启动。

## 0. 一页执行卡（每个交易日）

### 盘后（T 日 18:30–20:00，数据同步完成后）

- [ ] 确认 18:00 触发的 `tdxfeed.full_sync` 已完成，T 日日线已更新
- [ ] 检查数据：日期齐全、无重复、`close/open/prev_close > 0`、`amount > 0`
- [ ] 按第 2 节公式生成 cb≥3 信号，写入 `signals_YYYYMMDD.csv`
- [ ] 人工抽查前 3 只：涨停价、连板数、ST 身份、停牌/除权公告
- [ ] 20:00 前冻结名单；计算 T+1 涨停价/跌停价
- [ ] 在 journal 中为每条信号建一行，状态先记 `pending`

### 开盘（T+1 09:15–09:30）

- [ ] 09:15–09:25 看集合竞价，记录开盘价
- [ ] 开盘价 ≥ T+1 涨停价 − 0.005 → 记 `unbuyable_open_limit`，**不买、不等开板**
- [ ] 停牌/无报价 → 记 `suspended`，不买
- [ ] 其余按排序取前 3 只，09:25 竞价价（或 09:30 开盘价）买入
- [ ] 数量 = `floor(10% × 初始资金 / 成交价 / 100) × 100`；不足 1 手则跳过并记录
- [ ] 记录成交价、数量、滑点；未入选信号记 `not_selected`（仍进统计账本）

### 收盘（T+1 14:50–15:00）

- [ ] 盘中不止盈、不止损、不加仓、不做 T
- [ ] 14:57 检查是否封死跌停（收盘价 ≤ T+1 跌停价 + 0.005）
- [ ] 未跌停：按收盘价卖出，记录 `sell_price`、`close_T1`
- [ ] 跌停：记 `deferred`，T+2 开盘卖；若 T+2 仍封死跌停，按首个可成交价卖出
- [ ] 16:00 前补全 journal，核对当日信号数/成交数/买不进数/顺延数

## 1. 锁定参数（测试期内不得修改）

| 参数 | 锁定值 | 说明 |
|---|---|---|
| 信号 | T 日收盘封死涨停，且连板数 ≥ 3 | 收盘价 ≥ 涨停价 − 0.005 |
| 涨停价公式 | `floor(prev_close × (1+ratio) × 100 + 0.5 + 1e-7) / 100` | 与回测/特征表一致 |
| 涨跌幅 ratio | 主板 10%；主板 ST 5%；创业板 300/301、科创板 688/689 20% | 北交所不在股票池 |
| 连板数 cb | 连续收盘封死涨停的天数，断板即归零 | 用全历史日线计算，不用快照 |
| 入场 | T+1 开盘买入 | 只按开盘价，不在盘中追 |
| 入场排除 | T+1 开盘价 ≥ T+1 涨停价 − 0.005 | 买不进；**不等开板、不打板** |
| 出场 | T+1 收盘卖出 | 不做盘中止盈/止损 |
| 跌停顺延 | T+1 收盘 ≤ 跌停价 + 0.005 → T+2 首个可成交价卖 | 最长顺延到 T+3 收盘 |
| 单票仓位 | 初始资金的 10% | 按整手向下取整；不足 1 手跳过 |
| 每日新开仓 | 最多 3 只 | 同日多信号按第 2.4 节排序 |
| 排序 | cb 降序 → T 日成交额降序 → 代码升序 | 只影响执行账本，不影响统计账本 |
| 标准成本 | 双边 0.30% | 回测统一口径（佣金+印花税+滑点+保守缓冲）；实际成本逐笔记 |
| 实际成本 | 按券商佣金（含最低 5 元）+ 印花税 + 实际滑点逐笔记 | 与标准成本并行报告 |
| 测试期 | ≥ 3 个月，且 ≥ 100 笔成交 | 不足 100 笔则延长到 100 笔或 4 个月 |
| 停止线 | 达到样本后单笔均净 < +0.20% | 扣实际成本后 |
| 模型 | 不使用 | 模型在 cb≥3 池内无区分度 |
| 板块过滤 | 不进入执行账本 | 仅作并行影子曲线（lag1） |

## 2. 盘后选股流程（T 日收盘后）

### 2.1 数据闸门

数据源：`data/parquet/daily/*.parquet`（由 `tdxfeed.full_sync` 写入）。

1. T 日日线必须已更新到全市场（约 5,200 只）；缺失 > 0.5% 则当日不出信号。
2. 同一代码当日只能有一行；重复则停止并修数据。
3. `prev_close > 0`、`close > 0`、`open > 0`；`amount > 0`（amount 缺失时仅影响排序，不影响信号）。
4. 价格对齐异常：`|open/prev_close − 1| > ratio + 5%`、或日内振幅 > 2.5×ratio、或 T/T+1 有除权除息 → 该股当日只进影子日志，不交易。

### 2.2 信号计算

```text
ratio   = 0.05 if (ST 且主板) else (0.20 if 300/301/688/689 else 0.10)
limit_T = floor(prev_close * (1 + ratio) * 100 + 0.5 + 1e-7) / 100
sealed  = close_T >= limit_T - 0.005
cb      = 连续 sealed 天数（断板归零；停牌日无行情，不计入也不重置）
signal  = sealed and cb >= 3

limit_up_T1 = floor(close_T * (1 + ratio) * 100 + 0.5 + 1e-7) / 100
limit_dn_T1 = floor(close_T * (1 - ratio) * 100 + 0.5 + 1e-7) / 100
```

### 2.3 排除项（记入影子日志，不进入执行）

| 排除项 | 处理 |
|---|---|
| 上市不足 60 个交易日 | 新股涨跌幅制度不同，记 `new_stock` |
| T 或 T+1 停牌 | 记 `suspended` |
| T/T+1 除权除息 | 记 `corp_action`（复权价与涨停价口径可能失真） |
| 风险警示/退市整理公告 | 记 `risk_warning`，不交易 |
| 数据缺失/重复/异常 | 记 `data_error`，当日系统性缺失则暂停 |
| 北交所、ETF、债券 | 不在池内 |

ST 股**保留**（与回测一致），但必须标记 `is_st`；主板 ST 按 5%、双创 ST 按 20% 计算涨停价，ST 子集单独统计。

> 不要用 `scripts/daban_scan.py` 生成接力信号：它是盘中打板扫描器，与本规则无关。接力信号只看 T 日收盘后的日线。

### 2.4 排序与冻结

- 执行账本排序：`cb` 降序 → T 日 `amount` 降序 → `code` 升序；取前 3。
- 统计账本保留**全部**信号（含未入选），用于和回测的逐笔基线比较。
- 18:30 生成、20:00 冻结；冻结后不得因新闻、板块、盘感增删。
- 输出字段至少包含：`signal_date, code, name, cb, is_st, board, close_T, limit_T, amount_T, avg_amount_5d, limit_up_T1, limit_dn_T1, rank, selected`。

## 3. 开盘执行（T+1）

1. 09:15–09:25 记录集合竞价开盘价 `open_T1`。
2. `open_T1 >= limit_up_T1 - 0.005` → `unbuyable_open_limit`，**不挂单、不等开板**。
3. 停牌、无报价、`open_T1 <= 0` → `suspended` / `data_error`。
4. 其余按 09:25 竞价成交价买入；纸盘成交价即官方开盘价。
5. 数量：`shares = floor(0.10 × C0 / fill_price / 100) × 100`；`shares < 100` → `size_too_small`。
6. 单日最多 3 只；未入选记 `not_selected`。
7. 开盘跌停也照买（回测口径），不得主观跳过；记录 `open_limit_down` 标记。
8. 不追高：09:30 后不再买入；错过开盘即记 `missed`。

---

## 4. 收盘执行（T+1）

1. 盘中不设止盈/止损，不盯分时做 T。
2. 14:57 判断：`close_T1 <= limit_dn_T1 + 0.005` → 视为封死跌停，**不可卖**。
3. 未跌停：按 15:00 收盘价卖出；纸盘成交价即官方收盘价。
4. 跌停：`deferred=1`；T+2 开盘卖出。
5. T+2 开盘仍封死跌停：按 T+2 首个可成交价卖出；若全天封死，顺延 T+3，**最迟 T+3 收盘**按可成交价了结。
6. 顺延期间不加仓、不做 T、不换股。
7. 收盘后 16:00 前补全 journal。

## 5. 资金与仓位

- 纸盘初始资金记为 `C0`，测试期内不入金、不出金。
- 单票名义本金固定为 `0.10 × C0`，不按浮盈浮亏复利，保持风险恒定。
- 每日最多 3 只，最大暴露 30%；其余现金闲置是正常状态。
- **顺延持仓占用名额**：T+2 新开仓数 = 3 − 尚未卖出的顺延持仓数；没有名额则不买。
- 不加杠杆、不融资、不期权对冲。
- 不补仓、不摊薄、不对同一代码重复开仓。
- 账户回撤守卫：执行账本从峰值回撤 > 20% → 暂停 5 个交易日，复盘是否按规则执行；若确认是规则内亏损，恢复并记录，不改参数。

## 6. 两本账（必须同时记）

| 账本 | 范围 | 仓位 | 用途 |
|---|---|---|---|
| **执行账本（Book A）** | 每日排序前 3，实际可买 | 每只 10% × C0 | 真实资金曲线、回撤、容量、滑点 |
| **统计账本（Book B）** | **全部可评估** cb≥3 信号（含未入选） | 每笔固定 10% 名义本金，不做资金约束 | 与回测逐笔基线比较，检验 edge 是否还在 |

Book B 的每笔收益用两种成本口径各算一遍：

- `net_fixed = gross − 0.30%`（与回测可比）
- `net_actual = gross − 实际佣金 − 印花税 − 实际滑点`

两本账都排除 `unbuyable_open_limit`、`suspended`、`data_error`、`new_stock`、`corp_action`、`risk_warning` 的信号；这些信号只记数量，不计收益（`size_too_small` 只影响 Book A）。

## 7. Journal 字段（每信号一行）

| 字段 | 说明 |
|---|---|
| `signal_date` | T 日 YYYYMMDD |
| `entry_date` | 计划入场日（T+1）YYYYMMDD，用于执行匹配与日度分组 |
| `code / name` | 股票代码/名称 |
| `cb` | 连板数 |
| `is_st / board` | ST 标记；main10、st10、gem20（主板风险警示票自 2026-07-06 起由 5% 并轨 10%，该日之前的行仍标 st5） |
| `close_T / limit_T` | T 日收盘、涨停价 |
| `amount_T / avg_amount_5d` | T 日成交额、5 日均额 |
| `rank / selected` | 当日排序、是否进入执行账本 |
| `status` | pending/filled/unbuyable_open_limit/suspended/not_selected/size_too_small/new_stock/corp_action/risk_warning/missed/data_error/deferred_unsold |
| `open_T1 / limit_up_T1 / limit_dn_T1` | T+1 开盘、涨停价、跌停价 |
| `fill_price / fill_time / shares` | 纸盘成交价、时间、数量 |
| `open_limit_down` | T+1 开盘是否跌停（照买，但标记） |
| `slippage_open_bps` | `(fill_price/open_T1 − 1) × 10000`（纸盘应为 0） |
| `close_T1 / sell_price / sell_date` | 收盘价、卖出价、卖出日 |
| `deferred` | 是否因跌停顺延 |
| `defer_count` | 已顺延的交易日数（0/1/2） |
| `slippage_close_bps` | `(sell_price/close_T1 − 1) × 10000`（顺延则对实际卖出日参考价） |
| `gross_ret / net_fixed / net_actual` | 毛收益、标准成本净收益、实际成本净收益 |
| `notes` | 异常、公告、人工判断（只记录，不改变规则） |

## 8. 评估节奏与停止规则

### 8.1 每日 / 每周 / 每月

| 频率 | 指标 | 动作 |
|---|---|---|
| 每日 | 信号数、成交数、买不进数、顺延数、单笔净收益、数据异常 | 记 journal；异常当天标记 |
| 每周 | 滚动 20 笔均值、胜率、实际双边成本、未入选比例 | 周报；滚动 20 笔均值连续两周 < −0.5% 触发复盘（不直接停） |
| 每月 | Book B 单笔均净、日度等权 t、Book A 回撤、买不进率、顺延率、滑点 | 月报；同期重跑 chase 回测做对照 |

### 8.2 三个月判据

达到 **≥100 笔成交**且 **≥3 个月**后评估：

| 结果 | 条件 | 动作 |
|---|---|---|
| **停止** | Book B `net_fixed` 单笔均净 < **+0.20%** | 停止纸盘，写结案报告 |
| **停止** | 实际双边成本 > **0.60%** | 停止，先解决执行成本 |
| **暂停** | Book A 回撤 > 20%，或数据错误率 > 1%，或出现规则外操作 | 暂停、修复；规则外操作则本实验作废重来 |
| **通过** | 均净 ≥ +0.20%，成本 ≤ 0.60%，无规则外操作 | **继续纸盘到 6 个月/≥300 笔**，不直接上实盘 |
| **样本不足** | < 100 笔 | 延长到 100 笔或 4 个月，再判 |

### 8.3 统计功效说明

3 个月约 150–250 笔；纸盘回放的 1,017 笔单笔标准差约 5.7%，200 笔的均值标准误约 0.4%。12.5 个月诚实回放已经是 **−0.90%/笔**（§13.4），所以 3 个月纸盘要回答的不是"+0.63% 是否仍在"，而是"实时执行能否显著优于 −0.90% 的历史回放"。200 笔无法证明正期望（要把标准误压到 0.13% 约需 2,000 笔），因此 3 个月是**止损测试**，不是**证明测试**；通过后继续纸盘 6 个月，实盘决策另行评审。

### 8.4 同期对照

每个月用 `daban_backtest.py --mode chase --tp 100 --sl 100 --hold 1` 重跑纸盘窗口，逐笔对照：

- Book B 与回测共同信号的 gross 差异应 < 1bp；
- 差异 > 1bp 时先查数据/复权/涨停价，再查记录；
- 纸盘期间若出现回测没有的信号，说明数据或规则不一致，暂停。

## 9. 禁止事项（违反即实验作废）

- 不使用模型评分、新闻、板块、龙虎榜、情绪指标做二次筛选。
- 不因为“今天感觉不好”减少仓位或跳过信号。
- 不因为“板很高”加仓或“板很低”减仓；所有执行信号同权 10%。
- 不在盘中追买、不等开板、不打板、不做回封。
- 不改变持有期；不盘中止盈止损；不隔夜到 T+2（跌停顺延除外）。
- 不补仓、不摊薄、不对同一代码重复开仓。
- 不修改 cb 阈值、排序规则、排除项、仓位、成本口径。
- 不把 lag1 板块过滤混入执行账本；它只做并行影子。
- 不在 3 个月/100 笔之前下结论，也不因为短期盈利提前上实盘。

## 10. 异常处理表

| 事件 | 动作 |
|---|---|
| T+1 开盘涨停 | 不买，记 `unbuyable_open_limit`；不等开板 |
| T+1 全天停牌 | 不买，记 `suspended` |
| T+1 盘中临时停牌后复牌 | 按收盘规则处理；未买入则记 `missed` |
| T+1 收盘跌停 | 顺延 T+2 首个可成交价 |
| T+2 一字跌停 | 继续顺延，最迟 T+3 收盘了结，记录实际成交价 |
| T 日盘后突发风险警示/退市公告 | 记 `risk_warning`，不交易；已成交则按收盘规则卖 |
| T/T+1 除权除息 | 该信号只进影子，不交易；已成交按实际复权/现金处理并备注 |
| 数据缺失/重复 | 该股不交易；全市场缺失 > 0.5% 则当日暂停 |
| 交易所全日休市/半日市 | 按交易所日历；半日市仍按收盘价卖 |
| 券商/行情故障 | 纸盘记录理论价；若无法取得开盘/收盘价，记 `data_error`，不计入统计 |

## 13. 自动化脚本

实现：`tdxfeed/daban/paper.py`（规则引擎）、`scripts/daban_paper.py`（CLI）、`tests/test_daban_paper.py`（22 项测试）。状态与金额全部由日线数据推导，规则外无人工输入。

### 13.1 初始化

```bash
venv/bin/python scripts/daban_paper.py init --start-date 20261023 --capital 1000000
```

生成 `data/daban/paper/config.json`（冻结参数与 C0）、`journal.csv`（32 字段）、`signals/`、`reports/`。已存在时需显式 `--force` 才会覆盖。

### 13.2 每日流程

```bash
# 盘后：生成 T 日信号并写入 journal（pending）
venv/bin/python scripts/daban_paper.py signals --date 20261023

# T+1 收盘后：执行 pending（按当日开盘）、结算顺延、生成当日新信号
venv/bin/python scripts/daban_paper.py daily --date 20261024

# 任意时点：输出两本账并写 reports/report_*.json
venv/bin/python scripts/daban_paper.py report
```

`daily` 顺序固定为 execute → settle → generate；可重复运行。`journal` 以 `(signal_date, code)` 为键 upsert，且只在原记录仍为 `pending` 时更新，不会覆盖已成交记录。

### 13.3 状态机

```text
pending ──开盘涨停/停牌────────→ unbuyable_open_limit / suspended
   │
   ├──开盘可买 → filled ──收盘未跌停──→ 卖出（sell_date=T+1）
   │                    └─收盘跌停──→ deferred ──T+2 开盘/收盘──→ 卖出
   │                                          └─仍跌停──→ T+3 开盘/收盘强制了结
   │                                          └─T+3 仍停牌──→ deferred_unsold
   └──未入选 → not_selected（只进 Book B）
```

### 13.4 回放（backfill）与已验证基线

```bash
venv/bin/python scripts/daban_paper.py --paper-dir data/daban/paper_backfill_20261022 \
    init --start-date 20250905 --capital 1000000
venv/bin/python scripts/daban_paper.py --paper-dir data/daban/paper_backfill_20261022 \
    backfill --start 20250905 --end 20260924 --reset
```

2025-09-05 ~ 2026-09-24 结果（C0=1,000,000）：

| 口径 | 笔数 | gross | net_fixed | 胜率 |
|---|---|---|---|---|
| Book B 全部 | 1,017 | −0.603% | **−0.903%** | 49.9% |
| 非顺延 | 855 | +1.348% | **+1.048%** | 58.8% |
| 跌停顺延 | 162 | −10.900% | **−11.200%** | 2.5% |
| 纸盘保留、回测闸门丢弃的异常价 | 70 | −12.035% | −12.335% | 4.3% |

Book A：489 笔，PnL **−222,228.35**，收益 **−22.22%**，最大回撤 **−34.63%**。

关键结论：

- 旧基线 +0.633%/笔来自 min60 Part B：代码实际**没有实现任何跌停顺延**（直接在 T+1 收盘卖出），且回测闸门丢弃了 70 笔可执行的异常价交易；按本清单诚实执行，12.5 个月为负。全历史按同一规则为 −0.362%/笔。
- 非顺延子集仍为正（+1.048%），全部负贡献来自跌停顺延（−1.74pp）与异常价（−0.83pp）。
- 非顺延逐笔与 `daban_backtest.py --mode chase` 的 gross 最大误差 1.7e-8，差异来自上述两类交易，不是模拟器 bug。
- 46 条 `corp_action` 排除主要来自当前 ST 名称与历史涨跌幅制度不一致，属已知数据限制。

## 附：与回测口径的已知差异

| 项目 | 回测 | 纸盘 | 处理 |
|---|---|---|---|
| 每日笔数 | 全部信号（均 3.9 笔/日） | 执行账本最多 3 笔 | Book B 保留全部信号，消除选择偏差 |
| 排序 | 容量约束时按 cb 降序 | cb → amount → code | 记录排序，月度对照 |
| 新股/除权 | 未显式排除 | 排除并记影子 | 单独统计，不计入主结论 |
| 跌停顺延 | 按 T+1 收盘价卖出（未处理跌停） | T+2 首个可成交价，最迟 T+3 | 纸盘更真实；旧回测低估亏损 |
| 成本 | 固定 0.30% | 实际佣金+印花税+滑点 | 同时报告 `net_fixed` 与 `net_actual` |
| ST | 按名称 5% | 按名称 5%，标记并单独统计 | 一致 |

> 本清单只覆盖 cb≥3 接力；打板路径已在 12.5 个月 min60 数据上关闭，不在纸盘范围内。
> 接力在 6.7 年全历史按本清单回放为 **−0.362%/笔**（t=−1.05），12.5 个月为 **−0.90%/笔**（§13.4）。旧报告的 +0.39% 只识别了 4.57% 的顺延，按跌停价精确判定实际是 15.61%。纸盘的定位是验证实时执行能否推翻这个负结果，不是复制旧基线。
