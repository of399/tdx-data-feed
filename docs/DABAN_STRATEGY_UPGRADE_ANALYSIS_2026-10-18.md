# 打板策略升级改造分析 (2026-10-18)

> 触发：用户问"打板这一技术面短线策略，目前是否仍需升级改造"。
> 结论先行：**需要升级，且是结构性升级（目标函数错配），非过度工程**——但实施排在 v9r 训练之后。
> 方法：基于代码审计 + 模型/特征/数据源查证，结论附文件:行号证据。

## 一、打板策略现状盘点（查证实况）

| 组件 | 现状 | 证据 |
|---|---|---|
| 模型 | LightGBM `vpnl_huber_stage1`，**Huber 回归输出"预期 PnL"** | `scripts/predict.py:100` |
| 标签尺度 | `d_signal_5d_*` 命名 → **数日波段信号**（非次日） | `predict.py:97-100` 模型文件名 |

| **涨停池数据** | **无** | `ls data | grep 涨停/limit` 空 |

## 二、核心判断：存在"目标函数错配"这一结构性缺陷

**打板的本质** = 预测**次日涨停/溢价概率**（超短线 T+1，赚涨停溢价 + 连板接力）。

**当前模型做的事** = 预测**数日波段预期 PnL**（趋势/波段持仓，赚区间收益）。

| 维度 | 打板需要 | 当前模型提供 | 错配 |
|---|---|---|---|
| 时间尺度 | 次日（T+1）| 数日（5-10 日）| 🔴 错配 |
| 收益结构 | 涨停溢价、连板接力 | 区间趋势收益 | 🔴 错配 |
| 核心信号 | 封板强度、连板高度、题材 | 技术面动量 + 行业代理 | 🟡 部分 |
| 市场情绪 | 冰点/发酵/高潮/退潮周期 | 无（仅行业/市场代理）| 🔴 缺失 |

**一句话**：现在是用"波段模型"打"涨停板"，**能用（有信号）但不对口**。这解释了为什么 Top 1 常是"5 日 +46% 的妖股"（波段趋势的极致），而非"首板待接力的低位票"（打板的甜点区）。

## 三、改进方向（按 ROI 排序）

### P0-1 目标函数对齐（结构性，最高价值）

**改**：训练"次日涨停/溢价概率"专用模型，label 改为 `T+1 是否涨停` 或 `T+1 开盘溢价率`，而非数日 PnL。

**代码调整点**：
- 新增标注脚本：基于 parquet 日线计算 `T+1 涨停` 二分类标签（`close[t+1]/close[t] >= 1+limit`）
- 新增 `d_signal_5d_model_daban.txt`（LightGBM 二分类），`MODEL_REGISTRY` 加 `daban` 项

**风险**：需重新标注 + 训练 + 回测，工程量中等；**排在 v9r 训练之后**。

### P0-2 涨停/连板特征（纯加法，低风险，可先做）

现有 `limit_up_5d`（5 日涨停次数）、`limit_up_t1`（T-1 是否涨停）**无法区分"首板/二板/三板"和"连板高度"**——而打板接力的核心就是连板晋级。

**改**：`tdxfeed/features_5d.py` 加 3 个特征：
- `is_limit_up_today`：T-1 当日是否封涨停（已有 `limit_up_t1` 近似，但需区分"收盘涨停" vs "盘中摸板"）
- `consecutive_boards`：连续涨停板数（1=首板、2=二板、3+=三板及以上）
- `board_position`：首板/二板/三板离散特征

**风险**：纯特征加法，不影响旧模型（旧模型不读新特征），有 `test_stage1_factors_parity.py` 兜底。

### P1-1 涨停池数据 + 市场情绪温度（中价值，需新数据源）

打板高度依赖**市场情绪周期**（冰点期打板失败率 70%+，高潮期 80%+ 晋级），当前模型完全没有情绪维度。

**改**：新增涨停池采集脚本，计算每日市场级特征：
- `limit_up_count`：当日涨停家数
- `break_rate`：炸板率（封板后开板/总封板）
- `promotion_rate`：连板晋级率（昨涨停 → 今涨停比例）

**风险**：需新增数据采集（akshare 涨停池接口），工程量中等。

### P1-2 可执行性过滤（低风险，纯输出层）

当前 Top N 只按 PnL 排序，**不区分"一字板买不进"和"高开追高"**。

**改**：`scripts/predict.py` 输出层加：
- 一字涨停（开盘即封死）→ 标注"不可执行"，剔除出可买清单
- 高开 > +5% → 标注"追高风险"

**风险**：低，纯过滤逻辑。

### P2 盘中动态（长期）

- 集合竞价（9:25）后重新预测
- 盘中炸板回封信号

## 四、结论与建议

| 项 | 判断 |
|---|---|
| **是否需升级** | ✅ 需要——"目标函数错配"是真实结构性缺陷，非过度工程 |
| **最该先做** | P0-2（涨停/连板特征，纯加法低风险）+ P1-2（可执行性过滤，纯输出层）|
| **最高价值** | P0-1（目标函数对齐，重训专用打板模型）——但工程量大，排在 v9r 之后 |
| **当前清单可用性** | ✅ 现有清单（`DABAN_WATCHLIST_2026-10-19.md`）仍可执行——用波段模型打板虽不对口但 OOS 0.3475 有信号，配合纪律可用 |
| **实施顺序** | v9r 训练 → P0-2 + P1-2（低风险加法）→ P0-1（目标对齐重训）→ P1-1（情绪数据）|

## 五、一句话

> 打板策略**从零到一已跑通**（有模型、有防御、有清单、OOS 0.3475），但**核心缺陷是"用波段模型打涨停板"——目标函数错配**。真正该升级的是 P0-1（训专用打板模型），但当前 v9r 训练优先；**低风险的 P0-2（涨停特征）+ P1-2（可执行性过滤）可在 v9r 之后立即做**。
