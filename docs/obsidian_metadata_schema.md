# Obsidian 元数据与链接校验规则（Phase 2 统一规范，2026-10-16）

> 配套：`scripts/verify_obsidian_metadata.py`、`scripts/verify_obsidian_links.py`、`Makefile` 目标 `verify-obsidian-data`。
> 本文档是 Phase 2「数据完整性与链接功能」的**单一事实规则源**，所有校验器按此执行。

## 1. 模块分类（按 vault 内顶层目录）

| 顶层目录 | 模块 | 元数据策略 |
|---|---|---|
| `01-标的` | 个股一票一档 | 强校验（必填 4 字段 + 文件名编码）|
| `02-框架` | 投研框架/方法论 | 强校验 |
| `03-数据` | 数据字典/质量文档 | **豁免**（自动生成，无 frontmatter）|
| `04-回测` | 回测实验 | 强校验 |
| `05-知识库/数学` | 数学手写笔记 | 强校验（数学专属 8 字段）|
| `05-知识库`（非数学）| 其他知识笔记 | 强校验 |
| `06-模板` | 模板源 | 豁免（模板本身）|
| `07-日记` | 日记 | 豁免（由日记模板驱动）|
| `00-收件箱` | 草稿 | 豁免 |

## 2. 各模块必填字段

### 2.1 标的 / 框架 / 回测 / 知识库（非数学）

| 字段 | 类型 | 格式 | 说明 |
|---|---|---|---|
| `tags` | list[str] | 非空，含模块标签（`标的`/`框架`/`回测`/`知识库`）| 命名空间锚点 |
| `创建日期` | str | `YYYY-MM-DD` | ISO 日期 |
| `状态` | str | `skeleton`/`draft`/`active`/`done` | 笔记成熟度 |
| `模板` | str | 非空 | 生成模板名（如 `vault_seeder`）|

附加规则：
- **标的文件名**必须匹配 `^\d{6}-.+\.md$`（6 位代码 + 短横线 + 名称）
- 标的**代码去重**：按 6 位代码分组，全/半角 `A`/`Ａ` 视为同一代码，重复即报错
- `状态 == skeleton` 计为**警告**（笔记未填充），非错误

### 2.2 数学笔记（`05-知识库/数学/**）

| 字段 | 类型 | 格式 | 必填 |
|---|---|---|---|
| `title` | str | 非空 | ✓ |
| `type` | str | 非空（定理/定义/例子/反例/证明/开放问题/书索引）| ✓ |
| `domain` | str | 非空（概率统计/线性代数/…）| ✓ |
| `level` | str | 非空（本科/研究生/…）| ✓ |
| `status` | str | 非空 | ✓ |
| `tags` | list[str] | 含 `math-notes` | ✓ |
| `created` | str | `YYYY-MM-DD` | ✓ |
| `depends` | list[`[[link]]`] | 依赖列表（可空）| 条件 |
| `next_review` | str | `YYYY-MM-DD` 或 `2099-12-31` 占位 | 条件 |
| `used_by` | — | **禁止手工维护**（由 Dataview 反查）| ✗ |

附加规则：
- `next_review` 空值（YAML null）会被到期查询漏掉 → 必须显式 `2099-12-31` 占位
- `depends` 内 `[[link]]` 须为合法 wikilink（见 §3）

## 3. 链接解析规则

### 3.1 wikilink 语法

支持形态（Obsidian 标准）：
- `[[笔记名]]`
- `[[笔记名|别名]]`
- `[[笔记名#标题]]`
- `[[笔记名#标题|别名]]`
- `[[笔记名^块引用]]`

解析：取 `[[` 与 `]]` 间第一段，按 `|` 切出目标，按 `#` 切出标题/块；**目标 = 切分后的首段**。

### 3.2 目标解析（去重后查索引）

| 目标形态 | 解析规则 |
|---|---|
| 匹配 `^\d{4}-\d{2}-\d{2}$` | → `07-日记/<date>.md`（日期链接）|
| 其他 | → 按**笔记 basename**（去 `.md`）查全库索引；命中即有效 |

### 3.3 断链判定

目标在索引中不存在（且非日期链接缺失）→ **断链（错误）**。

### 3.4 循环依赖

从 `depends` 字段构建有向图 `note → target`，DFS 三色标记检测环；命中即**循环依赖（错误）**。
自引用（`A depends on A`）不计环，但记为提示。

## 4. 退出码

| 校验器 | 0 | 1 | 2 |
|---|---|---|---|
| `verify_obsidian_metadata.py` | 无错误（允许警告）| 存在字段错误/格式错误/重复 | 参数/依赖错误 |
| `verify_obsidian_links.py` | 无断链且无循环依赖 | 存在断链或循环依赖 | 参数/依赖错误 |

`make verify-obsidian-data` 串联两者，任一非零即整体非零。

## 5. 边界与错误处理

| 场景 | 处理 |
|---|---|
| 文件无 frontmatter（强校验模块）| 报「缺 frontmatter」错误 |
| YAML 解析失败 | 捕获异常，报「YAML 错误」并跳过该文件 graph 构建 |
| frontmatter 非字典 | 报格式错误 |
| 字段值为空字符串/None | 报「字段为空」错误 |
| 日期格式不符 `YYYY-MM-DD` | 报「日期格式错误」|
| `tags` 非列表或空 | 报「tags 非法」错误 |
| 链接 alias/heading 冗余 | 忽略，仅取目标 |
| 同笔记重复相同链接 | 去重后校验 |
| 链接指向自身 | 合法，不计断链 |
| `07-日记/<date>.md` 不存在 | 报断链（日期笔记缺失）|
